Servicio de Conectividad

Servicio de conectividad: descarga de datos Sentinel desde Europa por RedCLARA o internet dedicado, y acceso de los usuarios finales por internet.

Conectividad
17 apartados2 fig.4 tabl.
  • Descarga de datos Sentinel desde Europa mediante conexión dedicada vía RedCLARA o Internet dedicado (mínimo 3 Gbps).
  • Acceso del usuario final: Los usuarios accederán a la plataforma a través de internet mediante una dirección IP pública.

Para este proyecto, no es necesario disponer de una infraestructura de computación en nube de uso exclusivo. La solución puede operar en un entorno compartido donde los recursos sean utilizados de forma simultánea por múltiples clientes o proyectos, manteniendo los adecuados niveles de seguridad, aislamiento y rendimiento.
