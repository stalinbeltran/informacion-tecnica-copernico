PLIEGO · Pliego de Cargos — Servicio en la nube (IaaS, KaaS, DBaaS) · Capítulo 8.5.10

Conectividad:

Conectividad entre el centro de datos y las redes externas, con las dos opciones previstas.

Como parte de los requisitos de conectividad, el proveedor será responsable de proveer la conexión entre el punto de origen de los datos de las misiones Sentinel (Europa) y el centro de datos donde estará alojada la solución.

El proveedor deberá suministrar un medio de comunicación dedicado de 3 Gbps para la descarga de los datos de las misiones Sentinel, garantizando niveles de servicio que aseguren capacidad, estabilidad y disponibilidad continua. La solución técnica elegida será propuesta por el proveedor y deberá cumplir los SLA definidos en el pliego.

SLA mínimos:

  • Disponibilidad ≥ 99,9 %
  • Latencia máxima <170 ms para la opción 1 Enlace Internacional de Datos RedCLARA, si escoge la opción 2 Internet dedicado: <50ms
  • Pérdida de paquetes < 0,1 %

La redundancia (activa-activa o activa-pasiva) no es un requisito obligatorio, asumiendo que las descargas pueden programarse a lo largo del día.
