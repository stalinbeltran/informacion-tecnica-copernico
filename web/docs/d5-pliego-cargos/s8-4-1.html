PLIEGO · Pliego de Cargos — Servicio en la nube (IaaS, KaaS, DBaaS) · Capítulo 8.4.1

Resumen de Alcance:

Resumen: administración de infraestructura, DBaaS PostgreSQL, IaaS con KaaS y servicio de conectividad. No se requiere nube de cómputo de alto rendimiento.

Se requiere el suministro de servicios necesarios para la operación del Centro Regional Copernicus LAC Panamá, e involucra los siguientes componentes:

  1. Servicio de Administración de Infraestructura Gestión operativa de los componentes tecnológicos, incluyendo funciones relacionadas con el entorno KaaS y DBaaS (en fase operativa), monitoreo, trazabilidad, accesos, soporte y documentación técnica.
  2. DBaaS (Database as a Service) Provisión de una solución administrada de base de datos PostgreSQL con alta disponibilidad, respaldo, mantenimiento, escalabilidad y soporte técnico continuo.
  3. IaaS (Infraestructura como Servicio) Infraestructura virtualizada que incluye el suministro de máquinas virtuales, almacenamiento, balanceadores y red, así como la provisión de un servicio Kubernetes gestionado (KaaS) para orquestación de contenedores.
