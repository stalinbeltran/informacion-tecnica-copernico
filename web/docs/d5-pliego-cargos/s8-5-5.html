Requerimientos estimados de tráfico

Requerimientos estimados de tráfico entre máquinas virtuales y hacia el exterior.

Debido a la naturaleza del sistema CopernicusLAC, la mayor parte de la transferencia de datos se realiza internamente entre máquinas virtuales, y entre las máquinas virtuales y el almacenamiento de objetos con redes externas. Por tanto, se recomienda planificar aproximadamente 10 Gbps para tráfico Este–Oeste y 3 Gbps para tráfico Norte–Sur.

  • El servicio de IaaS debe tener compatibilidad con sistemas basados en Linux.
  • Se requiere que el proveedor cumpla con los reglamentos aplicables de la Unión Europea que correspondan al tipo de servicio ofrecido (infraestructura en la nube, protección de datos, ciberseguridad, etc.). Esto puede incluir, entre otros, el Reglamento General de Protección de Datos (GDPR), regulaciones sobre ciberseguridad. Se sugiere revisar las normativas relacionadas con la protección de datos al trabajar con instituciones europeas.
  • La base de datos se proporcionará a través de una solución de base de datos gestionada.
  • El centro de datos requiere estar ubicado en Panamá.
