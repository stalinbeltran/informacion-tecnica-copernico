Bases de Datos como Servicio (DBaaS):

Bases de datos como servicio: solución PostgreSQL administrada, con aprovisionamiento, respaldo y alta disponibilidad del lado del proveedor.

DBaaSPostgreSQL
  • Se requiere una solución administrada de base de datos como parte del servicio. Este servicio incluye aprovisionamiento, configuración, mantenimiento, actualizaciones, respaldo automático, escalabilidad y alta disponibilidad. El DBaaS garantiza alta disponibilidad, rendimiento y escalabilidad de la base de datos, componente integral de la plataforma.
  • Versiones de BD: el mínimo requerido es PostgreSQL ≥ 13 y PostGIS ≥ 3, pero se recomienda utilizar al menos PostgreSQL 16 y PostGIS 3.5.
  • La alta disponibilidad (HA) también debe aplicarse a PostgreSQL, ya que es un componente integral del sistema.
  • La base de datos PostgreSQL debe contar con un mecanismo de respaldo (backup). Las bases de datos ETCD del clúster de Kubernetes deben respaldarse; sin embargo, esto normalmente está gestionado en el servicio de KaaS.
