PLIEGO · Pliego de Cargos — Servicio en la nube (IaaS, KaaS, DBaaS) · Capítulo 8.5.16

Componentes del servicio:

Componentes del servicio, incluidas las funciones mínimas de DBaaS en etapa operativa.

  • Funciones mínimas relacionadas con el DBaaS (en etapa operativa):
    • Seguimiento técnico básico al servicio DBaaS, para asegurar su operatividad (respaldo, disponibilidad, performance básico).
    • Gestión de accesos administrativos para usuarios técnicos autorizados.
    • Coordinación con el proveedor DBaaS ante incidentes o comportamientos anómalos detectados por el middleware.
    • Verificación periódica de backups automáticos, según las políticas del servicio contratado.
    • Validación de alta disponibilidad activa (HA funcional).
    • Supervisión de recursos (uso de CPU, memoria, almacenamiento) y escalabilidad si aplica.
    • Documentación de ajustes, accesos y eventos críticos, para trazabilidad y auditoría.
  • Funciones mínimas relacionadas con el KaaS (en etapa operativa):
    • Configurar StorageClasses
    • Desplegar Ingresses específicos
    • Etiquetar nodos
    • Desplegar custom controllers
    • Editar deployments
    • Conectarse a pods
    • Revisar eventos y métricas para fines de diagnóstico (debug)
  • Administración de Sistemas Operativos. El Middleware se desplegará completamente sobre Kubernetes, y no se utilizará directamente la capa de IaaS. El mantenimiento del sistema operativo y la aplicación de parches de seguridad deben estar cubiertos como parte del servicio de KaaS. Sin embargo, se espera que se tenga conocimientos básicos de configuración y mantenimiento del sistema operativo dentro del equipo, pero no es un requisito clave para el despliegue y operación del Middleware.
  • Documentación de configuraciones aplicadas y cambios realizados.
