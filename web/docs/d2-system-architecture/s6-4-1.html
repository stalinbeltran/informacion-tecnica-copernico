Local Computer Execution

Ejecución local: usada en desarrollo y pruebas, con ciclos de feedback rápidos y depuración sencilla.

pp. 64
  • Purpose: Local execution is typically used during the development and testing phases. Developers can run applications on their local machines to debug and refine workflows before deploying them in more complex environments.
  • Implementation: The CWL-backed application package simplifies deployment by encapsulating all necessary tools, configurations, and dependencies. This ensures that the application behaves consistently across different local setups, eliminating environment-specific issues.
  • Advantages: Fast feedback loops, easy debugging, and iterative development.
