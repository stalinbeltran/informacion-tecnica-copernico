D2 · System Architecture Description · Capítulo 3.7.3

Integration Points

Controla el acceso al espacio de trabajo, front-end, datos, procesamiento, registro de aplicaciones y recursos aprovisionados.

Diagrama
pp. 34–351 fig.

The Authentication and Authorization component integrates with multiple other components within the CopernicusLAC platform to provide a cohesive and secure user experience:

  • User Workspace: Ensures that only authorised users can access and manage their personalised workspace environments.
  • Front-end Services: Controls access to web applications, interactive graphical tools, notebooks, and development environments based on user roles and permissions.
  • Data Discovery and Access Component: Manages user access to EO data, ensuring that only authorised users can search, retrieve, and download data.
  • Data Processing Component: Regulates access to processing services, allowing only authorised users to submit, monitor, and manage processing jobs.
  • Application Registry: Controls access to the application packages, ensuring that only authorised users can manage and deploy applications.
  • Resource Management: Coordinates with resource management to enforce security policies and access controls on provisioned resources.
