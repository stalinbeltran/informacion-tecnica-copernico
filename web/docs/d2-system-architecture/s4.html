Data Ingestion Process

Proceso completo de ingesta de datos EO: tecnologías empleadas, workflow paso a paso, selección del paquete de aplicación ETL, validación de contenido, perfil mínimo de metadatos STAC y enriquecimiento para visualización.

The purpose of this section is to describe the process by which EO data is integrated into the CopernicusLAC platform. This process is essential for ensuring that data is accurately brought into the system, validated, and made available for subsequent discovery and processing activities.

Data ingestion is the process of collecting, validating, and storing EO data. This process ensures that data is properly formatted, compliant with metadata standards, and securely stored for further use. The ingestion process might also involve pre-processing steps such as data or format transformation to ensure compatibility with the platform’s storage and processing systems.

The section outlines the technologies, workflows, and standards involved in data ingestion, ensuring consistency and reliability across the platform.
