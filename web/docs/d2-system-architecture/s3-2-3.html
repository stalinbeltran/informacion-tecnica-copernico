D2 · System Architecture Description · Capítulo 3.2.3

Integration Points

Conecta con ingesta (recibe metadatos), procesamiento (publica productos derivados), front-end, espacio de trabajo, visualización y descarga.

Diagrama
pp. 21–221 fig.

The Data Discovery and Access component integrates with multiple other components within the CopernicusLAC platform to ensure data flow and user interaction:

  • Data Ingestion Component: Provides metadata from the ingestion process to be indexed for discovery.
  • Data Processing Component: Facilitates the discovery of processed data products, making them available for user access and further analysis.
  • Front-end Services: Provides interfaces for users to search, visualise, and access data. This includes integration with the CopernicusLAC Portal and other web applications.
  • User Workspace: Allows users to save search results and access data within their personal workspaces for further analysis and processing.
  • Data Visualization Component: Uses visualisation links of each data item referenced in the Data Catalog using the Web Map Links and Rendering STAC extensions.
  • Data Download Functionality: Supports any data download functionality from any of the front-end services or data processing components, ensuring services and users can access the data they need.
