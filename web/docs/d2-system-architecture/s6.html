Application Packaging

Empaquetado de aplicaciones EO: visión general del proceso, CWL con ejemplos, contenedores, escenarios de despliegue, control de versiones, control de acceso, beneficios y los estándares de obligado cumplimiento.

The purpose of this section is to outline the application packaging process within the CopernicusLAC platform. Application packaging is essential for ensuring that EO data processing applications are properly structured, versioned, and ready for deployment. This process supports consistency, scalability, and reliability across various processing tasks, allowing applications to be easily deployed and managed within the platform’s infrastructure.
