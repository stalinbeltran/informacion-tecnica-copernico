D2 · System Architecture Description · Capítulo 3.3.1

Purpose

Infraestructura escalable para procesamiento sistemático y bajo demanda: limpieza, transformación, análisis y visualización de datos EO.

pp. 22

The Data Processing component of the CopernicusLAC platform is designed to transform raw EO data into valuable information and insights. This component enables users to perform various data processing tasks, including data cleaning, transformation, analysis, and visualisation. The primary purpose of this component is to provide a scalable infrastructure that supports both systematic and on-demand processing of EO data, ensuring that users can derive meaningful insights and actionable information from the data.
