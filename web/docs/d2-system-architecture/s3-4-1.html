D2 · System Architecture Description · Capítulo 3.4.1

Purpose

Almacenar, organizar y recuperar de forma segura los paquetes de aplicaciones EO para su despliegue y ejecución, con consistencia y reproducibilidad.

pp. 26

The Application Registry component of the CopernicusLAC platform is designed to manage the storage, organisation, and retrieval of EO application packages. This component ensures that application packages, including their metadata, code, configuration files, and container images, are securely stored and easily accessible for deployment and execution within the platform. The primary purpose of the Application Registry is to provide a centralised repository that supports the deployment and execution of EO applications, promoting consistency, reproducibility, and efficiency in data processing workflows.
