Software Stack

Kafka como bus de eventos, Argo Workflows para orquestación, Python/ETL para validación, CWL, Kubernetes, almacenamiento S3 y STAC para los metadatos.

pp. 19–20

The Data Ingestion component utilises a range of software tools and technologies to achieve its objectives:

  • Event Bus: Apache Kafka is used for managing the Argo Events event-driven data ingestion process bus. Kafka's capabilities in handling real-time data streams make it an ideal choice for this component.
  • Workflow Orchestration: Argo Workflows is employed to orchestrate the data ingestion workflows. Argo Workflows' Kubernetes-native design provides scalability and integration with containerized applications.
  • Data Validation and Pre-Processing: Custom Python scripts and ETL tools are used to validate and pre-process the incoming data. These tools ensure that the data meets the required quality standards before being stored or further processed.
  • Common Workflow Language (CWL): CWL is used to define and execute the data ingestion pipelines, ensuring portability and scalability.
  • OGC Best Practices for EO Application Package: The ingestion pipelines adhere to these best practices, ensuring compatibility and standardisation across the platform.
  • Container Orchestration: Kubernetes is used for deploying and managing the containerized ingestion pipelines. Kubernetes provides the necessary scalability and reliability to handle large-scale data ingestion tasks.
  • Storage Solutions: The platform employs S3-compatible object storage for data preservation, utilising its features like data versioning, lifecycle policies, and security mechanisms to ensure secure data management.
  • SpatioTemporal Asset Catalog (STAC): STAC specifications are used to organise and describe the data, making it easily searchable and accessible. Each dataset is accompanied by a corresponding STAC item, ensuring standardised metadata representation.
