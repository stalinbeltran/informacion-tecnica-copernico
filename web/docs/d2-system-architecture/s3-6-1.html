D2 · System Architecture Description · Capítulo 3.6.1

Purpose

Entorno personalizado donde cada usuario gestiona, ejecuta y analiza sus tareas de procesamiento y sus paquetes de aplicación.

pp. 31

The User Workspace component of the CopernicusLAC platform is designed to provide users with a personalised environment where they can manage, execute, and analyse their data processing tasks. This workspace offers tools and interfaces that enable users to access EO data, run processing jobs, and manage their own application packages. The primary purpose of the User Workspace is to enhance user productivity by offering a customizable and secure space tailored to individual needs and workflows.
