Integration Points

Sirve al motor de ejecución, al motor de workflows, al espacio de trabajo del usuario y, de forma indirecta, a los componentes de procesamiento e ingesta.

Diagrama
pp. 271 fig.

The Application Registry integrates with multiple other components within the CopernicusLAC platform to ensure application management and execution:

  • Application Execution Engine: Retrieves application packages from GitLab and deploys these as OGC API Processes. The registry ensures that the necessary application code, containers, and configurations are available to execute EO applications.
  • Processing Workflow Engine: The Processing Workflow Engine accesses the application packages and container images in the registry to orchestrate complex processing workflows, ensuring that all required dependencies and configurations are met.
  • User Workspace: Users interact with the Application Registry to retrieve operational application packages and copy them to their own private space. Each user workspace has dedicated software repositories in GitLab and a dedicated Harbor based container registry to manage private and operational packages and associated container registries.
  • Data Processing Component: The interaction with the Application Registry for the deployment and execution of applications is handled indirectly through the Data Processing Component, which orchestrates the retrieval and deployment of EO application packages on the Application Execution Engine.
  • Data Ingestion Component: Similar to the Data Processing component, the Data Ingestion component interacts with the Application Registry to retrieve application packages required for the ingestion, validation, and pre-processing of EO data.
