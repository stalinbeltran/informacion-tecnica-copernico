D2 · System Architecture Description · Capítulo 3.5.1

Purpose

Ofrecer interfaces accesibles e intuitivas para que los usuarios exploten las capacidades de la plataforma.

pp. 28

The Front-end Services component of the CopernicusLAC platform is designed to provide users with intuitive and accessible interfaces to interact with the platform’s capabilities. These services include the CopernicusLAC Portal, interactive graphical applications (e.g., QGIS, Panoply), notebooks (e.g., Jupyter), and an interactive development environment (e.g., VSCode). The primary purpose of the Front-end Services is to enable users to utilise the platform’s resources and capabilities through user-friendly interfaces.
