Deployment

Despliegue mediante charts de Helm sobre Kubernetes, con monitorización y escalado; el paquete soporta tres escenarios de ejecución distintos.

3 apartadospp. 63–65

Once the application package is stored in Harbor, it can be deployed within the CopernicusLAC platform. The deployment process involves:

  • Preparing Deployment Configurations: Managed through Helm charts, these configurations define how the application should be deployed in Kubernetes, including resource allocation, environment variables, and network settings.
  • Deploying to Kubernetes: The application is deployed as Kubernetes pods, with each pod running a containerized version of the application.
  • Monitoring and Scaling: Kubernetes monitors the application to ensure it operates correctly and can scale resources up or down based on demand.

Nevertheless the Application Package is designed to support a wide range of deployment scenarios, ensuring that EO applications can be executed across various environments. This flexibility is crucial for adapting to different computational needs, from local development to large-scale cloud deployments. The platform leverages the standardised packaging process, primarily based on CWL, to ensure that applications are portable and can be deployed consistently across these environments.
