D2 · System Architecture Description · Capítulo 3.7.1

Purpose

Marco de seguridad escalable que protege los recursos y servicios de accesos no autorizados.

pp. 34

The Authentication and Authorization component of the CopernicusLAC platform is designed to ensure secure access to the platform’s resources and services. This component manages user identities, controls access to various system functions, and ensures that only authorised users can access sensitive data and execute specific tasks. The primary purpose of this component is to provide a scalable security framework that protects the platform and its users from unauthorised access and potential security threats.
