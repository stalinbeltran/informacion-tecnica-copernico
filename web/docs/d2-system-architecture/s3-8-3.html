D2 · System Architecture Description · Capítulo 3.8.3

Integration Points

Da servicio al espacio de trabajo, front-end, descubrimiento y acceso, procesamiento, registro de aplicaciones y seguridad.

Diagrama
pp. 36–371 fig.

The Resource Management component integrates with multiple other components within the CopernicusLAC platform to provide a cohesive infrastructure management experience:

  • User Workspace: Manages the provisioning of dedicated namespaces and resources within the Kubernetes cluster for individual users, ensuring isolated and secure work environments.
  • Front-end Services: Instantiates and configures the necessary resources for the deployment and operation of front-end services, such as web servers and load balancers.
  • Data Discovery and Access Component: Ensures the necessary storage and compute resources are available for data ingestion, cataloguing, and retrieval processes.
  • Data Processing Component: Provisions the compute resources required for executing data processing workflows and handling large-scale EO data processing tasks.
  • Application Registry: Manages the infrastructure resources needed for storing and retrieving application packages and container images.
  • Authentication and Authorization: Coordinates with security components to enforce access controls and manage the infrastructure supporting identity and access management services.
