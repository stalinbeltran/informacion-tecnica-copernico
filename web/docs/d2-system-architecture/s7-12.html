ZOO Project

ZOO Project: framework de Web Processing Services que expone las aplicaciones EO como servicios web estándar.

pp. 75

The ZOO Project is an open-source platform that provides a framework for implementing and deploying Web Processing Services (WPS). In the CopernicusLAC platform, ZOO Project is utilised to handle geospatial processing tasks, allowing EO applications to be exposed as web services that can be accessed and executed via standard protocols. This capability enhances the platform's interoperability and enables users to integrate geospatial processing into their workflows.
