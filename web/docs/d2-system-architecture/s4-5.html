Metadata Profile

Perfil mínimo de metadatos basado en STAC: tabla con los campos obligatorios (id, geometry, bbox, datetime, assets…) que debe llevar todo activo geoespacial.

CopernicusLAC will encompass a wide spectrum of technical operations, from ingesting EO products to generating data from various processing tasks. Given this broad scope, it's essential to have a streamlined metadata approach. The minimal metadata profile, based on the STAC standard, offers a consistent description format that enhances data discovery, analysis, and management across all operational stages.

This profile serves both ingested and processed EO products. It integrates key attributes and descriptors, ensuring every data point, be it raw, ingested, or an outcome of processing, comes with a standardised and clear metadata. By recognizing the unique needs of both input and output datasets, the profile offers a unified yet adaptable metadata structure for all geospatial assets in CopernicusLAC.

An important component of the data ingestion process is the application of a minimal metadata profile to ensure consistency and interoperability. This profile defines the essential metadata fields required for each dataset and is stored in accordance with the STAC specification, enabling integration with the platform's data discovery and access components.

Table 1 shows a minimal metadata profile using STAC that defines a subset of mandatory fields that every geospatial asset should have. This definition will ensure consistency in metadata across all datasets while also aligning with the STAC specification.
