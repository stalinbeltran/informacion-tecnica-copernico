Integration Points

Se integra con descubrimiento y acceso, espacio de trabajo, front-end, visualización y el repositorio de aplicaciones.

Diagrama
pp. 24–251 fig.

The Data Processing component integrates with multiple other components within the CopernicusLAC platform to ensure data flow and interoperability:

  • Data Discovery and Access Component: Receives data products from the Data Discovery and Access Component for processing. Processed data products are indexed and catalogued for easy search and retrieval.
  • User Workspace: Provides a space where users can manage and execute their data processing tasks, as well as access and visualise the results of their processing jobs.
  • Front-end Services: Interfaces with the CopernicusLAC Portal and other web applications to allow users to submit processing jobs, monitor their progress, and access the results through the OGC API Processes interface.
  • Data Visualization Component: Supports the visualisation of processed data, enabling users to interact with and analyse the results.
  • Application Repository: Integrates with the Application Repository to access the application code and containers necessary for executing the EO applications.
