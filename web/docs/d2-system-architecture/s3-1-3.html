Integration Points

Se integra con CDSE y el Centro de Datos de Chile como fuentes, con el Repositorio de Aplicaciones para obtener los ETL y con Descubrimiento y Acceso para publicar lo ingerido.

Diagrama
pp. 191 fig.

The Data Ingestion component integrates with three other components within the CopernicusLAC platform to ensure data flow and interoperability:

  • Copernicus Data Space Ecosystem and Copernicus Data Centre (Chile): These external sources provide the raw satellite data that is ingested into the platform.
  • Application Repository: The Data Validation and Pre-processing Workflow Engine retrieves ETL (Extract, Transform, Load) applications from the Application Repository to manage the ingestion for all specific data collections or product types.
  • Data Discovery and Access: Once data is ingested and validated, it is stored and registered within the Data Discovery and Access component, making the data and web map tiles available and catalogued for user access.
