Unattended Execution Capability

MUST: las aplicaciones deben poder ejecutarse de forma desatendida, sin intervención humana.

pp. 70

All EO applications MUST be designed to run in an unattended or automated execution mode. This means that once deployed, the applications should be capable of executing their workflows, processing data, and producing outputs without the need for human intervention. This ensures that applications can be integrated into larger automated pipelines, supporting continuous operations and large-scale data processing within the CopernicusLAC platform.
