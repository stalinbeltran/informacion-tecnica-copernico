Resource Management

Aprovisionamiento dinámico con Crossplane, escalado coste-eficiente y monitorización automatizada con Prometheus y Grafana.

pp. 82–83

The resource management supports both scalability and performance on the platform providing services for:

  • Dynamic Resource Provisioning: The platform uses Crossplane to dynamically provision and manage cloud resources. This ensures that the platform can automatically allocate additional resources when needed, such as increasing storage capacity or adding more compute power during high-demand periods.
  • Cost-Efficient Scaling: By optimising resource allocation, the platform ensures that it scales in a cost-efficient manner. This involves balancing the need for additional

resources with the cost implications, ensuring that the platform remains both performant and economical.

  • Automated Resource Monitoring: The platform continuously monitors resource usage to ensure optimal performance. Tools like Prometheus and Grafana provide insights into resource consumption, helping administrators make informed decisions about scaling and resource allocation.
