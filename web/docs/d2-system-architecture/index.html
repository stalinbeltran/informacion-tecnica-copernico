D2 — System Architecture Description

Arquitectura técnica completa de la plataforma del Centro CopernicusLAC (Panamá): componentes, flujos de ingesta, catálogo STAC, empaquetado de aplicaciones EO, tecnologías, seguridad y escalabilidad.

Documento de diseño (D2) elaborado por Terradue para ESA que describe la arquitectura del sistema de la plataforma del Centro CopernicusLAC, el centro regional de Copernicus para América Latina y el Caribe con sede en Panamá. Define ocho componentes funcionales —ingesta, descubrimiento y acceso, procesamiento, registro de aplicaciones, servicios de front-end, espacio de trabajo de usuario, autenticación y gestión de recursos— y detalla, para cada uno, su propósito, implementación, puntos de integración y pila de software. Desarrolla además el proceso completo de ingesta de datos EO, el catálogo STAC y su API, el empaquetado de aplicaciones con CWL y contenedores, el catálogo de tecnologías base (Kubernetes, Argo, GitLab, Harbor, Keycloak, Titiler, PostgreSQL…), el marco de seguridad y cumplimiento (ESA PDP) y las estrategias de escalabilidad para soportar hasta 3.000 usuarios.
