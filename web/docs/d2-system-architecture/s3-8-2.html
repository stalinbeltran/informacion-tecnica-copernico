D2 · System Architecture Description · Capítulo 3.8.2

Implementation

Crossplane aprovisiona y configura recursos, escala dinámicamente, monitoriza el uso, gestiona secretos con ESO y aplica políticas.

pp. 36

The implementation of the Resource Management component involves several key elements designed to provide automated management of resources, utilising Crossplane:

  • Infrastructure Provisioning: Crossplane automates the provisioning of cloud infrastructure resources such as virtual machines, storage buckets, databases, and networking components.
  • Resource Configuration: Crossplane manages the configuration of infrastructure resources, ensuring they are set up according to best practices and platform requirements.
  • Dynamic Scaling: Crossplane supports dynamic scaling of resources based on predefined policies and real-time demand, ensuring the platform can handle varying workloads.
  • Resource Monitoring: Continuous monitoring of resource utilisation and performance to ensure optimal operation and to proactively address any issues.
  • Secret Management: The External Secrets Operator (ESO) is used to securely manage and inject secrets (e.g., API keys, passwords) into the resource configurations, ensuring sensitive information is handled securely.
  • Policy Enforcement: Ensuring that all resource provisioning and management actions comply with defined policies and standards, enhancing security and compliance.
