GitLab

GitLab: control de versiones y pipelines CI/CD del código de las aplicaciones EO.

pp. 73

GitLab serves as the version control system and Continuous Integration/Continuous Deployment (CI/CD) platform for the CopernicusLAC platform. GitLab is used to manage the source code of EO applications, track changes over time, and facilitate collaboration among developers. The CI/CD pipelines in GitLab automate the process of building, testing, and deploying applications, ensuring that updates are deployed quickly and reliably. This integration streamlines development workflows and helps maintain the integrity and consistency of the platform’s applications.
