Software Stack

PostgreSQL, PostGIS, PgSTAC, STAC API con FastAPI, GitLab, Harbor, S3, clientes CLI, Kubernetes, Crossplane, External Secrets Operator y API REST.

pp. 33

The User Workspace utilises a range of software tools and technologies to achieve its objectives:

  • PostgreSQL: Utilised for indexing and storing metadata. PostgreSQL's advanced querying capabilities enable search and retrieval of metadata.
  • PostGIS: used to extend the capabilities of the PostgreSQL relational database by adding support for storing, indexing, and querying geospatial data
  • PgSTAC: Stores all collection and item records as JSONB, allowing for any STAC custom fields to be stored and retrieved transparently.
  • STAC API with FastAPI: Provides a standardised interface for programmatic access to the catalogued data, enabling users to perform detailed searches and retrieve metadata and data assets. The FastAPI interface validates requests and data sent to the PgSTAC backend.
  • GitLab: Used for version control, allowing users to manage their application packages and track changes.
  • Harbor: Used to store and manage container images associated with user-defined applications.
  • Data Storage: S3-compatible object storage or other scalable storage solutions are used to store user data and processing results.
  • CLI Clients: Provides command-line tools for data access, discovery, and processing.
  • Processing Job Management: Interfaces with the Data Processing Component to manage the submission, monitoring, and retrieval of processing jobs.
  • Kubernetes: Each user has a dedicated namespace on the Kubernetes cluster, managed by Crossplane.
  • Crossplane: Manages the provisioning of infrastructure resources and Helm releases, ensuring that users have the necessary resources for their tasks.
  • External Secrets Operator (ESO): Manages sensitive information and secrets, ensuring secure storage and retrieval.
  • RESTful API: Provides programmatic access to workspace functionalities, allowing for user and admin operations.
