Software Stack

PostgreSQL, PostGIS, PgSTAC, STAC API con FastAPI, almacenamiento S3, Titiler y el servicio de URLs firmadas.

pp. 22

The Data Discovery and Access component utilises a range of software tools and technologies to achieve its objectives:

  • PostgreSQL: Utilised for indexing and storing metadata. PostgreSQL's advanced querying capabilities enable search and retrieval of metadata.
  • PostGIS: used to extend the capabilities of the PostgreSQL relational database by adding support for storing, indexing, and querying geospatial data
  • PgSTAC: Stores all collection and item records as JSONB, allowing for any STAC custom fields to be stored and retrieved transparently.
  • STAC API with FastAPI: Provides a standardised interface for programmatic access to the catalogued data, enabling users to perform detailed searches and retrieve metadata and data assets. The FastAPI interface validates requests and data sent to the PgSTAC backend.
  • Data Storage Solutions: S3-compatible object storage is used to store and manage the actual data files, ensuring scalable data access.
  • Titiler: Backend service for serving map tiles based on OGC Web Map Tile Service (WMTS) requests, supporting dynamic generation of tiles from COG products.
  • Signed URL Service: Generates temporary, secure URLs that allow users to download data directly from the S3 storage, ensuring secure and controlled access.
