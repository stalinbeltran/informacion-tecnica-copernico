Software Stack

GitLab, Harbor, PostgreSQL gestionado para metadatos y control de acceso mediante IAM.

pp. 28

The Application Registry utilises a range of software tools and technologies to achieve its objectives:

  • GitLab: Used to store the application packages, including CWL descriptions, code, and configuration files. It provides version control and metadata management.
  • Harbor: Used to store and manage container images associated with application packages, ensuring that containers are easily accessible and deployable.
  • Metadata Database and Search: PostgreSQL, provided as a service by the cloud provider, is used within GitLab to manage the metadata associated with each application package and to enable querying capabilities.
  • Access Control: Implemented using IAM (Identity and Access Management) solutions within GitLab and Harbor to ensure secure access to the registry.
