Titiler

Titiler: teselado dinámico de datos geoespaciales, especialmente COG, para visualización en tiempo real.

pp. 75–76

Titiler is a dynamic tiling service that generates map tiles from geospatial data, allowing for real-time visualisation of EO datasets within the CopernicusLAC platform. Titiler is particularly well-suited for handling COGs, enabling users to interact with large datasets by streaming only the necessary portions of the data. This technology enhances the platform's

visualisation capabilities, providing users with the ability to explore and analyse geospatial data through interactive maps.
