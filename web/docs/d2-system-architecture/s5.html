Data Discovery, Access and Visualisation

Descubrimiento, acceso y visualización de datos: el estándar STAC, la API de catálogo con ejemplos de consultas, el acceso directo a datos en la nube con COG, la interfaz gráfica del portal y la integración de Titiler.

Data discovery in the CopernicusLAC platform is designed to be comprehensive and user-friendly, ensuring that users can locate and retrieve EO data relevant to their needs. The process is supported by metadata cataloguing, indexing, and an intuitive interface that allows users to interact with the data in meaningful ways. Central to this design is the integration of the STAC and the STAC API, which provide a standardised framework for describing and accessing EO data.
