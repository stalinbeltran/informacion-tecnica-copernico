Software Stack

React o Angular, D3.js/Leaflet/OpenLayers, JupyterHub, VSCode, OAuth/OpenID Connect, APIs REST, Docker y CI/CD de GitLab.

pp. 30–31

The Front-end Services utilise a range of software tools and technologies to achieve their objectives:

  • Web Frameworks: Tools such as React or Angular are used to develop responsive and interactive web applications.
  • Visualisation Libraries: Libraries such as D3.js, Leaflet, or OpenLayers are used to create interactive maps and visualisations.
  • JupyterHub: JupyterHub provides access to the platform’s services and web applications in a Software-as-a-Service (SaaS) mode. Through JupyterHub, users can engage with containerized Interactive Graphical Applications (IGAs), specialised geospatial data exploration web apps, and customizable dashboards, enhancing their ability to interact with and analyse EO data.
  • Notebooks: JupyterHub is used to manage and provide access to Jupyter notebooks in a Software-as-a-Service (SaaS) mode. This setup allows users to perform interactive, code-based data analysis and visualisation within their web browsers, leveraging containerized environments for consistent performance and scalability across multiple users.
  • Interactive Development Environment (IDE): Tools like VSCode are provided for application development, testing, and debugging.
  • Authentication and Authorization: Tools such as OAuth or OpenID Connect are used to manage user authentication and authorization.
  • APIs: RESTful APIs are used to interact with backend services, facilitating data access, processing job submission, and retrieval of results.
  • Containerization: Docker is used to containerize front-end services, ensuring consistent deployment and scalability.
  • Continuous Integration/Continuous Deployment (CI/CD): Tools such as GitLab CI/CD are used to automate the deployment and updating of front-end services.
  • Visualisation Clients: Tools that interact with the Titiler backend in the Data Discovery and Access component for generating and displaying map tiles.
