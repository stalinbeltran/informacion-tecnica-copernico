Prometheus

Prometheus: recolección y almacenamiento de métricas del sistema, con consulta en tiempo real y detección proactiva de incidencias.

pp. 74–75

Prometheus is an open-source monitoring and alerting toolkit designed for reliability and scalability. In the CopernicusLAC platform, Prometheus is used to collect and store metrics

from various components of the system, providing insights into the platform's performance and health. Prometheus scrapes metrics from configured endpoints, stores them, and allows for real-time querying and analysis.

Prometheus is expected to be deployed within the platform's Kubernetes environment, leveraging its ability to monitor containerized applications at scale. This setup ensures that the platform can continuously monitor key metrics such as CPU usage, memory consumption, and network activity, enabling proactive detection of issues and resource management. By integrating Prometheus, the platform can maintain high availability and performance, quickly identifying and resolving potential bottlenecks or failures.
