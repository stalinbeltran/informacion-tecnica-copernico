D2 · System Architecture Description · Capítulo 3.5.2

Implementation

Portal web centralizado, aplicaciones gráficas interactivas, notebooks, IDE, autenticación integrada, clientes de visualización contra Titiler y aplicaciones web de caso de uso.

pp. 28–29

The implementation of the Front-end Services involves several key elements designed to ensure an efficient user experience:

  • CopernicusLAC Portal: A centralised web-based portal that provides users with access to data discovery, retrieval, and visualisation tools. The portal offers an intuitive user interface with clear categorizations, filters, and search capabilities.
  • Interactive Graphical Applications: Tools like QGIS and Panoply are integrated to provide users with advanced capabilities for visualising and analysing geospatial data.
  • Notebooks: Platforms like Jupyter Notebooks allow users to perform complex data analyses and visualisations through an interactive, code-based interface. These notebooks can access data directly from the User Workspace.
  • Interactive Development Environment (IDE): Tools like VSCode are provided to enable users to develop, test, and debug their applications in a user-friendly environment.
  • User Authentication and Authorization: Secure access to front-end services through integrated authentication and authorization mechanisms.
  • Visualisation Clients: Integrated visualisation clients access the Titiler backend in the Data Discovery and Access component to convert geospatial raster data into web-friendly map tiles for display on web applications.
  • Use Case / Service Web Applications: These applications are being developed in parallel projects to provide essential EO-based information co-designed with stakeholders. They enhance the platform's relevance and usability in addressing key areas such as disaster risk reduction and climate event monitoring.
  • Resource Management: The resource management component instantiates or deploys the front-end services, ensuring that they are properly configured and available for user access.
