Comprehensive Documentation

SHOULD: acompañar cada aplicación con documentación de funcionalidad, entradas/salidas, ejemplos y despliegue.

pp. 71

All EO applications SHOULD be accompanied by detailed documentation. This includes descriptions of the application’s functionality, input/output specifications, usage examples, and deployment instructions. Documentation is crucial for facilitating the use, maintenance, and troubleshooting of applications within the platform.
