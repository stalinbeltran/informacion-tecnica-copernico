D2 · System Architecture Description · Capítulo 3.2.1

Purpose

Permitir a los usuarios buscar, descubrir y acceder a los datos EO ingeridos de forma organizada y usable.

pp. 20

The Data Discovery and Access component's primary purpose is to enable users to search, discover, and access the EO data ingested into the system. This component ensures that the data is organised, searchable, and retrievable in a user-friendly manner, supporting the platform's goals of providing accessible and usable data for various applications.
