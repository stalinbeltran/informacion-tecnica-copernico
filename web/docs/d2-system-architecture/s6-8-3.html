D2 · System Architecture Description · Capítulo 6.8.3

Docker Containerization

MUST: encapsulación en contenedores Docker con todas sus dependencias; se recomiendan imágenes base ligeras.

pp. 70

EO applications MUST be encapsulated within Docker containers. These containers should include all necessary dependencies and configurations to ensure that the application runs consistently, regardless of the underlying infrastructure. Developers are encouraged to use lightweight base images and to optimise container size and performance.
