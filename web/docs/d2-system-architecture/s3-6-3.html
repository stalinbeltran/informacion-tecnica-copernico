Integration Points

Se integra con descubrimiento y acceso, procesamiento, registro de aplicaciones, ArgoCD, Crossplane y los servicios de front-end.

pp. 32–33

The User Workspace integrates with multiple other components within the CopernicusLAC platform to provide user experiences for:

  • Data Discovery and Access Component: Provides users with access to the EO data stored within the platform. Users can search, retrieve, and process data using CLI clients directly from their workspace.
  • Data Processing Component: Allows users to submit processing jobs and manage workflows. The workspace interfaces with the Data Processing Component to execute user-defined tasks.
  • Application Registry: Users retrieve application packages from the Application Registry to their workspace. This enables them to manage their private copies of application packages, including version control and container management.
  • ArgoCD: Synchronises the user repositories with the Kubernetes cluster to ensure that the desired state of resources and applications is consistently applied.
  • Crossplane: Manages the provisioning of infrastructure resources such as S3 buckets, Helm releases, and other cloud resources within the user's namespace.
  • Front-end Services: The front-end services, such as notebooks and visualisation tools, utilise the User Workspace to access data and execute processing tasks on behalf of the user.
