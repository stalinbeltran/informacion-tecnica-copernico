Software Stack

Crossplane, Kubernetes, External Secrets Operator, Terraform (opcional), Prometheus y Grafana, Helm y las APIs de los proveedores de nube.

pp. 37–38

The Resource Management component utilises a range of software tools and technologies to achieve its objectives:

  • Crossplane: An open-source control plane that enables the provisioning and management of cloud infrastructure resources through Kubernetes-native APIs.
  • Kubernetes: Used to orchestrate and manage containerized applications and infrastructure resources, providing scalability and reliability.
  • External Secrets Operator (ESO): Manages and injects secrets into Kubernetes resources, ensuring secure handling of sensitive information.
  • Terraform: Optionally used for defining and provisioning infrastructure as code, complementing Crossplane's capabilities.
  • Prometheus and Grafana: For monitoring resource utilisation and performance metrics, providing visibility into the health and efficiency of the infrastructure.
  • Helm: Manages the deployment and configuration of Kubernetes applications, ensuring consistent and repeatable setups.
  • Cloud Provider APIs: Interfaces with cloud service providers (e.g., AWS, Azure, GCP) to provision and manage infrastructure resources.
