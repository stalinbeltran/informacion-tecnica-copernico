Metadata Enrichment for Visualization

Uso de las extensiones STAC Rendering y Web Map Links para generar composiciones (color verdadero, infrarrojo) y enlaces a servicios WMTS/XYZ, con ejemplos JSON.

RenderingWeb Map LinksJSON
pp. 45–47

To facilitate visualisation of the dataset in the full scope of the platform services, the ingestion process leverages STAC extensions to provide rendering configurations and web map links for visualisation services.

The process leverages the Rendering2 STAC Extension to define rendering configurations, such as creating true-colour or colour-infrared composites from different bands. If the STAC Item and its assets are already in the COG format and include rendering information, the dedicated and collection specific ETL process focuses on generating Web Map Links3 using the Web Map Links STAC Extension. This allows for the integration with web map services like OGC WMTS and XYZ, providing end-users with access to visual representations of the data.

  1. Visualisation STAC Extensions:
    1. Rendering Extension: This extension provides details on how the STAC Item can be visualised (e.g., combining different bands to create a composite image).

2 https://github.com/stac-extensions/render 3 https://github.com/stac-extensions/web-map-links

  1. Web Map Links Extension: This extension provides links to web maps (e.g., OGC WMTS and XYZ) that can render the STAC Item using the specified visualisation configuration.
  2. Enrichment Process:
    1. Existing Visualisation Information: If the STAC Item already includes rendering information, the ETL process adds Web Map Links URL templates to implement these configurations.
    2. Generating New Assets: For datasets that do not have visualisation-ready assets, the collection-specific / or a dedicated ETL process generates new COG and updates the STAC Item with rendering information and Web Map Links.
    3. Publication: The enriched STAC Item and new assets are published to the object storage and registered in the catalog.

An important aspect of the ETL process is the enrichment of data to enable visualisation. This involves leveraging the Rendering STAC Extension and the Web Map Links STAC Extension:

  • Rendering Extension: Provides rendering configurations for the STAC Item, such as combining different bands to create true-colour or colour-infrared composites.
  • Web Map Links Extension: Supplies links to web maps (e.g., OGC WMTS and XYZ) that can render the STAC Item using the specified visualisation configuration.

If the STAC Item included in the .zip archive contains the Rendering extension and the assets are in the Cloud Optimized Geotiff (COG) format, the ETL process focuses on generating the Web Map Links.

Here is an example of a STAC Item with rendering information:

"renders": {
  "trc": {
    "title": "True-colour composite",
    "assets": [
      "red", "green", "blue"
    ],
    "resampling": "nearest",
    "rescale": [
      [0, 5000], [0, 5000], [0, 5000]
    ]
  },
  "civ": {
    "title": "Colour-infrared composite",
    "assets": [
      "red", "green", "nir"
    ],
    "resampling": "nearest",
    "rescale": [
      [0, 5000], [0, 5000], [0, 5000]
    ]
  }
}
