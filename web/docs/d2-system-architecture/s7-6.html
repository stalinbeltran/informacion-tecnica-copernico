Harbor

Harbor: registro de imágenes con escaneo de vulnerabilidades, firma de imágenes y RBAC.

pp. 74

Harbor is an open-source container image registry used by the CopernicusLAC platform to store and manage Docker images securely. Harbor provides advanced security features, such as vulnerability scanning, image signing, and access control, ensuring that only trusted and verified images are deployed on the platform. By organising images into projects and enforcing role-based access control (RBAC), Harbor allows for the management of containerized applications, contributing to the overall security and reliability of the platform.
