Software Stack

Calrissian, Argo Workflows y Events, Docker/podman, Kubernetes, Python y GDAL, almacenamiento S3 y ZOO Project como implementación de OGC API Processes.

pp. 25–26

The Data Processing component utilises a range of software tools and technologies to achieve its objectives:

  • Calrissian1: a CWL runner for kubernetes used to submit and manage data processing workflow executions on Kubernetes, ensuring portability and scalability.
  • Argo Workflows: Orchestrates the execution of CWL-defined processing pipelines, providing scalable workflow management.
  • Argo Events: Provides an event-driven framework to trigger workflows based on specific events, ensuring responsive and automated processing.
  • Docker, podman: Containerizes processing tasks to ensure consistent and reproducible execution across different environments.
  • Kubernetes: Manages and orchestrates the execution of containerized processing tasks, providing dynamic scaling and reliability.
  • Python and GDAL: Commonly used for developing custom data processing scripts and tools, leveraging the extensive libraries and capabilities of Python and the Geospatial Data Abstraction Library (GDAL).
  • S3-Compatible Object Storage: Stores processed data, ensuring scalable data access and management.
  • Zoo Project is a software solution that implements the OGC API Processes. This standard provides a standardised web service interface for initiating and managing data processing tasks from front-end services.

1 https://github.com/Duke-GCB/calrissian

  • Deployment Interface (Part 2): Defines the standards and protocols for deploying EO applications within the environment.
  • Execution Interface (Part 1): Specifies the standards for executing the deployed applications, detailing how users can initiate and manage processing jobs.
