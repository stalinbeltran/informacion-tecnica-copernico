User Roles

Cinco roles de usuario: Data Explorer, Service Stakeholder, Data Analyst, Service Developer y Operator, con sus actividades características.

Roles
pp. 9–10

As defined in D1, the CopernicusLAC platform supports a variety of user roles, each with distinct responsibilities and interactions with the system. These roles ensure the effective operation and utilisation of the platform, facilitating access to, processing, and analysis of EO data. Below is a summary of the primary user roles within the CopernicusLAC platform, highlighting their key activities and how they contribute to the overall functionality and goals of the system:

  • Data Explorer
    • Uses the CopernicusLAC Portal for data search and retrieval.
    • Utilises catalogue and geospatial tools for data exploration.
    • Performs simple analytics with visualisation and filtering services.
    • Conducts analysis within the platform to leverage computational capabilities.
  • Service Stakeholder
    • Interacts with service web applications co-designed with stakeholders.
    • Focuses on risk and recovery mapping, vulnerability assessment, and EO monitoring of extreme events.
    • Provides feedback on web application functionality and usability.
    • Applies insights from applications to domain-specific tasks.
  • Data Analyst
    • Accesses and manipulates data sets through the CopernicusLAC Portal and APIs.
    • Uses analytical techniques and tools for data processing and analysis.
    • Creates reports and visualisations to present findings.
    • Utilises interactive graphical applications (e.g., QGIS, Panoply) and notebooks for detailed analysis.
  • Service Developer
    • Develops algorithms to process and analyse EO data delivered in dedicated web applications in the activities of a parallel project to provide essential EO-based information to specific stakeholders.
    • Tests and refines code using the interactive development environment.
    • Collaborates with Operators to integrate algorithms into workflows.
  • Operator
    • Manages deployment and orchestration of containerized applications.
    • Monitors system performance and ensures high availability.
    • Performs regular maintenance and system updates.
    • Deploys new services developed by Algorithm Developers.
    • Addresses technical issues and supports other user roles.
