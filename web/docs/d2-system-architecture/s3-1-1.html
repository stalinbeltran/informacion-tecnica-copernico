D2 · System Architecture Description · Capítulo 3.1.1

Purpose

Soporta tres niveles de ingesta según el papel del dataset: registro de metadatos, registro con copia local y registro con calibración.

pp. 17

The Data Ingestion component is crucial for the CopernicusLAC platform as it manages the initial intake of data from external sources. Its primary purpose is to support a flexible data ingestion strategy that accommodates multiple levels of ingestion, tailored to the dataset’s role, user requirements, and operational scenarios. These levels include:

  1. Metadata Registration: Ensuring that datasets hosted externally are discoverable by registering their metadata and access points without duplicating the original data.
  2. Metadata Registration with Dataset Copying: Facilitating local storage of datasets when frequent access or integration with platform workflows is required.
  3. Metadata Registration with Dataset Calibration: Supporting pre-processing or transformation of datasets during ingestion to align with specific analytical or quality requirements.

This component ensures that incoming data, whether stored locally or accessed externally, is validated, indexed, and made accessible for subsequent processing and analysis.
