GitLab for Version Control

SHOULD: gestionar código, workflows CWL y Dockerfiles en GitLab, usando sus pipelines CI/CD.

pp. 70

The source code, CWL workflows, and Dockerfiles for EO applications SHOULD be managed using GitLab. Developers should follow best practices for version control, including tagging releases and maintaining clear documentation of changes. GitLab’s CI/CD pipelines should be used to automate the build, test, and deployment processes.
