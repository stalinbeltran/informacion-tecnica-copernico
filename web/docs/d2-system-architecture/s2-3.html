System Components

Los ocho componentes de la plataforma entregada como PaaS agnóstico de nube: ingesta, descubrimiento y acceso, procesamiento, repositorio de aplicaciones, front-end, espacio de trabajo, autenticación y gestión de recursos.

PaaSDiagrama
pp. 10–121 fig.

The Platform relies on a comprehensive suite of software tools and protocols to streamline various processes involved in EO data management and application development with the objective of providing a Cloud-agnostic EO Data Hosting and Exploitation environment. The components are delivered as a fully-fledged Platform-as-a-Service (PaaS) that supports:

  • Efficiency in Data Handling: Streamline the process of EO data ingestion and calibration, ensuring data integrity and accuracy.
  • Discoverability: Facilitate swift and precise data searches, aided by a geospatial and temporal querying mechanism.
  • Flexibility in Integration: Allow integration of external tools and data processing applications.
  • Versatile Execution: Provide a diverse execution environment ranging from local servers to cloud-based infrastructures.
  • User Engagement: Foster an interactive and intuitive user experience, offering a platform where applications can be easily searched, reviewed, and executed.

The diagram below shows the several key components, each fulfilling a specific role in the overall architecture.

Key components:

  • Data Ingestion: Manages the ingestion of data from external sources, ensuring that data is validated and pre-processed before being stored or used.
  • Data Discovery and Access: Stores metadata about available data, manages the actual data storage, and provides tools for users to search, discover, and visualise data. It also manages secure access to data.
  • Data Processing: Facilitates communication between different processing components, manages workflows for processing data, and provides access to various data processing services, supporting additional functionalities as needed.
  • Application Repository: Stores packages of applications used for processing and analysis, manages containers for running applications, and ensures version control for applications and workflows.
  • Front-end Services: Acts as the main interface for users to interact with the platform, including specific web applications designed for different use cases, tools for interactive data analysis (such as QGIS, JupyterLab, and VS Code), a development environment for creating and testing applications, and support for interactive computational notebooks for data analysis.
  • User Workspace: Provides users with personal workspaces that include version control, storage, and repositories for managing their work and data.
  • Authentication and Authorization: Manages user authentication and authorization, ensuring secure access to the platform.
  • Resource Management: Oversees the allocation and management of system resources, ensuring operation and scalability.
