D2 · System Architecture Description · Capítulo 3.1.2

Implementation

Pipelines automatizados con arquitectura dirigida por eventos, validación por nivel de ingesta y workflows en CWL conformes a las buenas prácticas OGC de EO Application Package.

pp. 18

The implementation of the Data Ingestion component combines automated pipelines and workflow management systems to ensure the systematic and reliable intake of data from external sources, such as the Copernicus Data Space Ecosystem and the Copernicus Data Centre in Chile. The component supports multiple levels of ingestion, allowing the platform to adapt dynamically to various operational needs and dataset requirements:

  • Automated Data Ingestion Pipelines: These pipelines are designed to handle large volumes of incoming data automating the processes of metadata harvesting, dataset copying, and, when required, dataset calibration. The ingestion workflows are flexible, dynamically selecting the appropriate level of ingestion based on the dataset's purpose:
    • For metadata registration, pipelines validate and catalog metadata for discovery without copying the original data.
    • For metadata registration with dataset copying, pipelines download and validate the datasets before storing them locally.
    • For calibration scenarios, additional processing steps, such as format conversion or georeferencing, are applied before registration and storage.
  • Data Validation and Pre-Processing: Validation checks are integral to all ingestion levels, ensuring the integrity, completeness, and quality of ingested data. For metadata-only ingestion, the system focuses on verifying compliance with the STAC specification. For datasets requiring copying or calibration, validation includes checksum verification and content-specific checks to confirm readiness for storage and analysis.
  • Event-Driven Architecture: An event-driven approach underpins the ingestion system, utilizing event buses to manage the flow of data through the pipeline. This architecture supports scalable and flexible data handling, dynamically adjusting to variations in data loads, such as high-frequency acquisitions or large-volume transfers.
  • Standards Compliance: The pipelines workloads are developed using CWL and adhere to the OGC Best Practices for EO Application Package to ensure portability and scalability.
