D2 · System Architecture Description · Capítulo 6.8.4

Adherence to Metadata Standards

MUST: las salidas deben cumplir el perfil mínimo de metadatos y catalogarse en formato STAC.

pp. 70

Applications MUST produce outputs that comply with the platform’s metadata standards, ensuring that data is discoverable and usable within the platform. This includes adhering to the minimal metadata profile and ensuring that outputs are catalogued using the SpatioTemporal Asset Catalog (STAC) format.
