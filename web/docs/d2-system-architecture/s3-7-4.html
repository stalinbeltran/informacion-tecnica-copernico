Software Stack

Keycloak como solución única, con OAuth/OpenID Connect, integración LDAP, JWT e IAM.

pp. 35–36

The Authentication and Authorization component utilises Keycloak for a comprehensive solution, eliminating redundancy and ensuring streamlined implementation:

  • Keycloak: An open-source identity and access management solution providing single sign-on, identity brokering, user federation, authentication mechanisms (OAuth, OpenID Connect), role-based access control (RBAC), multi-factor authentication (MFA), and audit logging.
  • OAuth and OpenID Connect: Integrated within Keycloak for secure authorization and authentication.
  • LDAP Integration: Keycloak integrates with LDAP for managing user credentials and profiles.
  • JWT (JSON Web Tokens): Used by Keycloak for securely transmitting user information during authentication and authorization processes.
  • IAM (Identity and Access Management): Keycloak manages roles, permissions, and access policies across the platform.
