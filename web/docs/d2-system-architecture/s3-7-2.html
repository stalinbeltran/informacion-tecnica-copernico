D2 · System Architecture Description · Capítulo 3.7.2

Implementation

Keycloak cubre identidades, autenticación (OAuth/OpenID Connect), políticas de autorización, RBAC, SSO, MFA y auditoría.

pp. 34

The implementation of the Authentication and Authorization component involves several key elements designed to provide a secure and user-friendly experience, utilising the full stack of services provided by Keycloak:

  • User Identity Management: Keycloak manages user identities, including registration, authentication, and profile management.
  • Authentication Mechanisms: Secure authentication protocols, such as OAuth and OpenID Connect, are implemented through Keycloak to verify user identities and ensure secure access to the platform.
  • Authorization Policies: Keycloak defines and enforces authorization policies that determine what actions users can perform and what resources they can access based on their roles and permissions.
  • Role-Based Access Control (RBAC): Keycloak assigns roles to users and manages permissions based on these roles to ensure appropriate levels of access.
  • Single Sign-On (SSO): Keycloak enables users to log in once and gain access to multiple related but independent systems without re-authenticating.
  • Multi-Factor Authentication (MFA): Keycloak supports adding an additional layer of security by requiring users to provide two or more verification factors to gain access.
  • Audit Logging: Keycloak provides audit logging of authentication and authorization activities to monitor for suspicious behaviour and ensure compliance with security policies.
