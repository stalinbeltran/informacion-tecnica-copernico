The high-level functional diagram shown in Figure 2 provides a visual representation of the system's structure, highlighting the main components and their interactions. It serves as a blueprint for understanding how data flows through the system and how the different modules interact with each other.

The architecture of the platform is designed with an array of interfaces and integrations, ensuring operations throughout the data acquisition, storage, and retrieval processes. One of the core features of this architecture is its diverse set of API endpoints. These endpoints play a pivotal role in handling real-time data streaming from various platforms and stakeholders.

The selected design leverages cloud-agnostic resources with modern technologies and standards to optimise data discovery, access, application development, hosting, and execution that are being used in several operational platforms.
