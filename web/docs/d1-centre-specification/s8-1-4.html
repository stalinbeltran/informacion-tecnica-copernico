Security & Availability

Seguridad y disponibilidad: RBAC y MFA obligatorios, cifrado extremo a extremo, auditoría completa, cumplimiento RGPD y ESA, y objetivo de disponibilidad ≥99,5 %.

pp. 39
  • Access Control:
    • Mandatory Role-Based Access Control (RBAC) and Multi-Factor Authentication (MFA) for user and admin access.
  • Data Protection:
    • End-to-end encryption at rest and in transit.
    • Comprehensive audit logging for all access and operational actions.
  • Compliance:
    • Adherence to GDPR and ESA security standards.
  • High Availability Objectives:
    • The system must meet a ≥99.5% uptime target, with full support for disaster recovery and automated failover.
