External Connectivity

Conexión externa de 3 Gbps o superior e integración con redes regionales de alta velocidad como el programa BELLA.

3 GbpsBELLA
pp. 24–25
  • High-bandwidth internet connections (3 Gbps or higher) to support data exchange with external data centres, users, and collaborators. Connections should be capable of handling large volumes of data transfer with minimal latency.
  • Integration with regional high-speed networks, such as the BELLA program, to facilitate timely access to Copernicus observations and regional data distribution.

The infrastructure provider should supply and manage the high-bandwidth internet connections and ensure integration with regional high-speed networks.

The Platform operations should manage external data transfers, ensuring efficient use of bandwidth, and optimising data exchange processes.
