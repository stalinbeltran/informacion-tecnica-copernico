Data Processing Requirements

Ingesta automatizada por lotes y en tiempo real, entorno de procesamiento cloud-native y elástico, middleware entregado como código abierto, y registro y monitorización completos.

pp. 16

Data processing is essential for ingesting EO data and allow its subsequent transformation into actionable information according to the LAC community needs. The Platform must support scalable, automated processing workflows to handle various data processing needs. These workflows should align with recognized best practices for EO applications, ensuring standardised processing.

  • Data Ingestion:
    • Implement automated and scalable data ingestion processes that can handle both batch and real-time data streams. The system must support efficient data ingestion pipelines capable of managing ancillary datasets and user-provided data in standard formats.
    • Ensure data quality, integrity and completeness through monitoring and management mechanisms for the data ingestion processes.
  • Data Processing:
    • Deploy a cloud-native processing environment that supports scalable and elastic data processing capabilities to handle varying workloads. The system should be able to manage complex workflows and integrate standard EO data processing toolboxes and additional tools identified in the CopernicusLAC Services procurement.
    • Support both on-demand and systematic processing workflows, allowing the system to scale up resources as required to support Disaster Risk Reduction (DRR) activities at national and continental scale with satisfactory performance.
    • Develop middleware components to facilitate data processing, including data transformation, aggregation, and analysis. Middleware must be delivered as open-source to enable future modifications and enhancements by local operators.
    • Ensure that the processing workflows are designed to follow recognized best practices for EO application packages, ensuring standardisation, compatibility, and efficiency.
    • Provide comprehensive logging and monitoring capabilities to track the performance and health of data processing workflows.
