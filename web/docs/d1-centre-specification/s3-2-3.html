Compliance Requirements

Estándares de obligado cumplimiento: OGC 20-089r1 para EO Application Package, CWL, Docker/podman con imágenes OCI, S3, Kubernetes, STAC, OGC WMTS, OGC API Features y Processes; y entrega de todo el middleware como código abierto.

OGCCWLOpen source
pp. 19–21

Compliance requirements ensure that the system adheres to industry standards and best practices, promoting interoperability, and enabling future enhancements. The Platform must integrate industry standards and best practices into its operations, ensuring the system's reliability, security, and scalability.

  • Standards Compliance:
    • Ensure the system complies with relevant standards and best practices, such as the OGC Best Practice for EO Application Package (OGC 20-089r1), which promotes standardised, interoperable, and reusable EO applications.
    • Package EO data processing applications using the Common Workflow Language (CWL) to ensure interoperability and ease of data processing and analysis workflow sharing.
    • Use Docker, podman or equivalent tool producing OCI images for containerization of EO applications and their dependencies in portable container images.
    • Adopt industry de facto standards such as S3 for storage interfaces and Kubernetes for the orchestration of containerized applications.
    • Utilise SpatioTemporal Asset Catalog (STAC) for indexing and discovering geospatial data.
    • Implement OGC Web Map Tile Service (WMTS) to provide georeferenced map tiles, supporting efficient and scalable delivery of map data.
    • Use OGC API - Features for accessing and querying geospatial features in a standardised way, promoting interoperability and ease of integration.
    • Implement OGC API - Processes to facilitate the execution of geospatial processes via standard web interfaces, enabling integration and automation of complex workflows.
  • Open Source:
    • Deliver all middleware and tools developed under this procurement as open-source to facilitate future modifications and enhancements by local operators.
    • Ensure that open-source components are well-documented and supported, providing clear guidelines for future development and integration. Documentation should include detailed instructions for deploying, configuring, and using the software, as well as contributing to its development.
    • Encourage the use of existing open-source tools and libraries that comply with OGC standards and best practices, fostering an ecosystem of interoperable and reusable components.
  • Technical Implementation:
    • Adopt CWL for defining and executing data processing workflows.
    • Use Docker, podman or equivalent tool producing OCI images to containerize applications, ensuring that they run consistently regardless of where they are deployed.
    • Utilise Kubernetes as the orchestrator for managing containerized applications with automated deployment and scaling ensuring efficient resource utilisation and high availability.
    • Integrate S3-compatible storage solutions for scalable and flexible object storage, supporting large volumes of EO data ensuring compatibility with a wide range of tools and services, facilitating data management and access.
    • Implement STAC to standardise the way geospatial data is indexed and discovered, making it easier to search and retrieve EO data.
    • Utilise STAC for defining data processing geospatial data inputs.
    • Use OGC WMTS to serve georeferenced map tiles, enhancing the performance and scalability of map data delivery.
    • Integrate OGC API - Features to provide standardised access to geospatial features, supporting efficient querying and data retrieval.
    • Implement OGC API - Processes to enable the execution of geospatial processes via standardised web API interfaces, supporting automation and integration of complex workflows.
    • Integrate with standard EO data processing toolboxes and custom-developed tools that adhere to best practices, ensuring the system can effectively process and analyse EO data in a standardised manner.
    • Conduct regular audits and assessments to ensure continued compliance with OGC standards and best practices, adapting to any updates or changes in the standards.
