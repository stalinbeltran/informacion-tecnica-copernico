D1 · CopernicusLAC Centre Specification and Performance Requirements · Capítulo 4.2.3

Application Software

Portales web, APIs de acceso programático, sistemas de catálogo y gestión de datos, y herramientas de visualización; el proveedor aporta el DBaaS.

pp. 24
  • Web-based portals for user access to data and services, featuring intuitive interfaces and authentication mechanisms.
  • APIs for programmatic access to data and processing services, supporting integration with third-party applications and services.
  • Data catalog and management systems to facilitate data discovery, access, and retrieval, supporting metadata standards and providing efficient search capabilities.
  • Visualisation tools to enable interactive exploration and analysis of EO data, supporting geospatial functionalities and user-defined parameters.

The infrastructure provider should offer Database as a Service (DBaaS) as part of their services. Developing and maintaining the web-based portals, APIs, data catalogues, and visualisation tools, ensuring they are optimised for performance, security, and user experience are responsibilities of the Platform.
