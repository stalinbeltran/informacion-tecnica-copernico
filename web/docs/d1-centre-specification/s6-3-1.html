Capacity Planning

Hasta 3.000 usuarios concurrentes, con gestión de accesos para evitar sobrecargas y escalado horizontal para crecer sin apenas parada.

3.000 usuarios
pp. 33

The system should support up to 3,000 concurrent users, ensuring reliable access to data and services. User access should be managed to prevent overloads, prioritising critical users and tasks. Horizontal scaling should be implemented to add more resources as user demand grows, ensuring the system architecture supports scalability with minimal downtime or reconfiguration.
