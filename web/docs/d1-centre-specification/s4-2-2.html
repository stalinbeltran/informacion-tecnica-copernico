Middleware

Kubernetes para orquestación de contenedores y Argo Workflows con soporte CWL para las tuberías de procesamiento, más integración con toolboxes EO estándar.

KubernetesArgo
pp. 23
  • Container orchestration platforms, such as Kubernetes, to manage the deployment, scaling, and operation of containerized applications across clusters of hosts. Kubernetes should support automated scheduling, autoscaling, self-healing, and service discovery.
  • Workflow management systems, such as Argo Workflows, to orchestrate complex data processing pipelines, ensuring efficient resource utilisation and task execution. These systems should support the CWL standard to facilitate the creation, scheduling, and execution of workflows that adhere to recognized best practices for EO applications.
  • Integration with standard EO data processing toolboxes and custom-developed tools to handle specific processing requirements.

The infrastructure provider should offer the container orchestration platform and ensure its reliable operation, including automated scheduling, autoscaling, self-healing, and service discovery features.
