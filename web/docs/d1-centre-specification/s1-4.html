Document Structure

Mapa de los siete capítulos y de lo que aborda cada uno.

pp. 5–6

This Service Specification document is divided into the following Chapters:

  • Chapter 1 (current) - This section provides an overview of the project detailing the context and objectives of the CopernicusLAC initiative and establishes the framework for the implementation and operation of the CopernicusLAC Centre Platform.
  • Chapter 2 - User Roles: This section details the various user roles within the CopernicusLAC platform, outlining their responsibilities and interactions with the system. It describes how different users will access, process, and analyse EO data and how the system is designed to accommodate these roles.
  • Chapter 3 - This section details the necessary features and capabilities of the Platform, including both functional and non-functional specifications. It outlines requirements for data hosting, processing, and exchange, as well as performance standards and security measures.
  • Chapter 4 - This section specifies the physical and software infrastructure required for the Platform. It includes the necessary hardware, software, and network components to support the system's operations.
  • Chapter 5 - This section provides guidelines for the operational phases of the Platform. It includes details on pre-operational and operational demonstrations, maintenance requirements, and support and training programs.
  • Chapter 6 - This section defines the key performance metrics for the Platform, including system availability, data throughput, latency, and user capacity. These metrics will be used to ensure the system meets the required performance standards.
  • Section 7 - This section provides a comprehensive summary of all the requirements identified in this document.
