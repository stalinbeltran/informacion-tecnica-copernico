Performance Metrics

Al menos 0,350 TB/h de ingesta y procesamiento, con picos de hasta 3,5 TB/h; menos de 1 hora de latencia extremo a extremo y máximo 5 minutos para flujos en tiempo real.

0,350 TB/h3,5 TB/h
pp. 32–33

The system should support a data ingestion and processing throughput of at least 0,350 TB per hour, with scalability to handle peak data loads up to 3,5 TB per hour during high-demand periods. Data processing latency should be minimised, with an end-to-end

processing target of less than 1 hour for standard data products. Real-time data streams should have a maximum latency of 5 minutes from ingestion to availability. Performance monitoring tools should be implemented to track data throughput and latency continuously, optimising data processing pipelines to reduce bottlenecks and improve efficiency.
