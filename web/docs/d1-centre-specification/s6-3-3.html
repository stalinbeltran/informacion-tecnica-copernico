Proposed KPI

KPI propuestos: capacidad y escalabilidad de usuarios, y completitud de la oferta de datos medida como porcentaje de peticiones satisfechas.

pp. 33
  • User Capacity and Scalability: Measure the number of concurrent users supported and system response times under varying loads, reporting on resource utilisation and scaling events.
  • Data Offer Completeness: Measure the percentage of successful data items requests made by the users.
