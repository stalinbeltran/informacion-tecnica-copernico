Performance and Operational Requirements

Rendimiento: soporte para ≥3000 usuarios concurrentes, escalado horizontal en cómputo, almacenamiento y servicios, y monitorización en tiempo real.

pp. 39
  • Designed to support ≥3000 concurrent users with guaranteed responsiveness.
  • Horizontal scaling is required across compute, storage, and service tiers.
  • Performance monitoring tools must ensure real-time tracking of:
    • Resource utilization,
    • Data throughput and latency,
    • System health and user traffic patterns.
