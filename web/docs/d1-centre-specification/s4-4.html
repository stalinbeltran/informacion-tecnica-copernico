The CopernicusLAC platform will rely on a scalable infrastructure to support its extensive user base and data processing needs. The infrastructure must ensure high availability, efficient resource allocation, and support for various services such as Kubernetes, virtual machines (VMs), load balancing, database management, and storage. The key requirements it will follow include:

  • Kubernetes Managed Service: A High Availability (HA) configuration supporting up to 1000 nodes, ensuring scalability and failover management for container orchestration.
  • Virtual Machines (VMs): A range of VMs with varying configurations/flavours to support core platform components and specific processing needs, optimised for high-performance computing.
  • Dedicated Load Balancer: A managed service in HA configuration with at least 4 Gbps capacity to distribute traffic across services.
  • Database Management: PostgreSQL in HA configuration to ensure data availability, integrity, and performance.
  • Storage Solutions: A combination of block storage (SSD) for fast access (e.g. 20,000 IOPS, 1 ms read/write latency), object storage for online data, and cold storage for archiving previous years' data, ensuring scalability and data integrity.
