Storage Systems

Almacenamiento S3 compatible con al menos 22 PB para retención a largo plazo, arquitectura distribuida y tolerante a fallos, NAS/SAN y sistemas de copia de seguridad automatizados.

22 PBS3
pp. 22–23
  • Integration with S3-compatible storage to enable scalable and flexible object storage for large volumes of EO data. The object storage solution used for long-term retention and archival of EO data shall have a minimum capacity of 22 PB.
  • Distributed storage architecture to ensure data redundancy and fault tolerance. Solutions should be able to support scalable and resilient data storage needs.
  • Network-attached storage (NAS) and/or storage area network (SAN) configurations to provide efficient and high-speed data access.
  • Backup systems to ensure data integrity and availability, with automated backup schedules and secure off-site storage options.

The infrastructure provider should offer and maintain the distributed storage architecture, NAS/SAN configurations, backup systems, and S3-compatible storage solutions supporting event notifications for object creation and removal.

The platform should integrate the storage solutions with the processing workflows, managing data redundancy and fault tolerance, setting up automated backup schedules, and ensuring secure off-site storage.
