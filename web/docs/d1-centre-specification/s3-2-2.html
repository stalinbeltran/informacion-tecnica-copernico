Security Requirements

Cifrado en reposo y tránsito (HTTPS/SFTP con TLS 1.2+), auditorías, IDS/IPS, MFA y RBAC, cumplimiento del RGPD y del marco ESA PDP, minimización y retención de datos, y plan de respuesta a incidentes.

RGPDESA PDPMFA
pp. 18–19

Security requirements ensure that the system protects data and user information from unauthorised access and breaches, maintaining data confidentiality, integrity, and availability.

  • Data Security:
    • Implement comprehensive security measures to protect data integrity, confidentiality, and availability.
    • Employ encryption for data at rest and in transit using secure protocols such as HTTPS and SFTP with TLS 1.2 or later to safeguard sensitive information.
    • Ensure regular security updates and patches for all software components to address vulnerabilities.
    • Conduct regular security audits and vulnerability assessments to identify and mitigate potential security risks.
    • Implement intrusion detection and prevention systems (IDS/IPS) to monitor and respond to suspicious activities.
  • User Authentication and Authorization:
    • Use authentication mechanisms to verify the identity of users accessing the system.
    • Implement multi-factor authentication (MFA) to enhance user authentication security.
    • Enforce role-based access control (RBAC) to manage user permissions and access levels based on their roles and responsibilities.
    • Regularly review and update access controls to ensure that only authorised personnel have access to data and system functionalities.
  • Compliance:
    • Ensure compliance with relevant data protection regulations, such as GDPR, to safeguard personal data and maintain user privacy.
    • Adhere to the ESA Personal Data Protection Framework, which includes adopting the level of protection resulting from the EU Standard Contractual Clauses for data transfer to third countries, as applicable.
    • Ensure that any transfer of personal data outside the agreed territory is authorised by the ESA Data Protection Officer (DPO) and subject to adequate safeguards.
    • Maintain comprehensive logs and audit trails to support compliance reporting and forensic analysis in case of security incidents.
  • Data Minimization and Retention:
    • Transfer only the necessary categories of personal data for specific processing activities related to the CopernicusLAC initiatives, adhering to the principles of data minimization and purpose limitation.
    • Ensure that personal data is retained only for as long as necessary to fulfil the purposes for which it was collected and processed, in compliance with applicable legal and regulatory requirements.
  • Technical and Organisational Measures:
    • Implement secure data transfer protocols, ensuring the secure transmission of personal data.
    • Provide adequate training for staff involved in data processing and transfer, covering data protection principles and secure data handling practices.
    • Establish secure authentication mechanisms, including strong passwords and MFA, to restrict access to data transfer systems.
    • Develop an incident response plan that includes procedures for promptly addressing any security incidents affecting personal data, including notifications to relevant authorities and data subjects as required by GDPR Article 33.
