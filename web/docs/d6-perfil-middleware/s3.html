PERFIL · Comparación de perfil y definición del rol · Capítulo 3

Gap Analysis

Análisis de brechas entre lo contratado y lo solicitado, para evitar duplicidad de roles y fijar responsabilidades.

Brechas
3 apartados

This document presents a gap analysis between the scope of services already contracted (IaaS / KaaS / DBaaS) and the Middleware Administrator profile requested by ESA for the Copernicus Platform. The objective of this analysis is to clarify overlaps, partial coverage, and uncovered responsibilities, in order to avoid duplication of roles and to clearly define accountability.

En este capítulo

3.1

Key Findings

Tres hallazgos: buena parte ya está cubierta por el contrato; algunas funciones solo parcialmente, donde el contrato llega al nivel de infraestructura y ESA espera nivel de aplicación; y quedan sin cubrir los dominios funcionales del Middleware, el almacenamiento S3, la gestión avanzada de incidentes y de cambios y la optimización del rendimiento.

Ver el detalle → 3.2

Conclusion

Conclusión: el rol que pide ESA es distinto del alcance contratado; hay solape operativo parcial, pero las responsabilidades de capa de aplicación no están cubiertas por el contrato vigente.

Ver el detalle → 3.3

Recommendation

Recomendación: definir formalmente el Administrador de Middleware como rol complementario centrado en operación, diagnóstico funcional y coordinación con ESA y el proveedor.
