Scope

Cubre cuatro áreas funcionales —ingesta, descubrimiento, visualización y acceso— más los procesos de prueba, validación y gestión de cambios.

pp. 5

This document covers the interfaces between the CopernicusLAC platform and external systems, with a focus on four key functional areas: data ingestion, data discovery, data visualisation, and data access. The scope includes the specification of communication protocols, data formats, security measures, and compliance requirements that govern these interfaces. Additionally, the document outlines the testing, validation, and change management processes that ensure the reliability and integrity of the platform’s external interactions.
