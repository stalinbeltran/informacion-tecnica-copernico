Tile Visualisations

Un producto puede tener varias visualizaciones (color verdadero, falso color); se acceden mediante las plantillas de enlace de la extensión Web Map Links, con rel "xyz".

JSON
pp. 29–30

Multiple tile visualisations may be available for a single product, such as true colour and false colour composites. These visualisations are accessed via tile link templates provided in the STAC Item’s links section. These templates follow the Web Map Links STAC extension and are identified by their titles.

"href": "<view-url>/collections/sentinel-s2-l1c-cogs/items/S2A_MSIL1C_20231122T102331_N0509_R065_T32TM R_20231122T122209/tiles/WebMercatorQuad/{z}/{x}/{y}@1x?&assets=nir&assets=green&assets=red&col or_formula=Gamma%20RGB%201.5%20Saturation%201%20Sigmoidal%20RGB%2010%200.3&rescale=1,6000&resc ale=1,6000&rescale=1,6000", "type": "image/png", "title": "False colour composite visualised through a XYZ" } ... } ], ... ] }

In this example:

  • The rel attribute is set to "xyz", indicating that these are XYZ tile links, a common format for web mapping applications.
  • The href attribute includes placeholders {z}, {x}, and {y}, which must be replaced with the zoom level and the zero-based column and row numbers to fetch the appropriate tile image.
