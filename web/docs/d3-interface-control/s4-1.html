Overview

El catálogo se expone mediante la API REST de STAC, un estándar consolidado que organiza los productos EO en colecciones y permite buscarlos y filtrarlos.

pp. 17

The Data Discovery functionality in the CopernicusLAC system is provided through a catalog that utilises the SpatioTemporal Asset Catalog (STAC) REST API. This API enables the discovery and access of Earth Observation (EO) products by organising them into collections and allowing users to search and filter these collections based on specific criteria.

The STAC API is a widely adopted standard in the geospatial community, facilitating interoperability and ease of integration with other systems. This section will describe how data can be discovered using the STAC API, including methods for obtaining collection information, accessing metadata, filtering data, and retrieving specific items. Examples of API requests and responses are provided to illustrate the usage of these interfaces.
