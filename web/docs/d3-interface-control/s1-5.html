Document Structure

Mapa de los seis capítulos y de lo que aborda cada uno.

pp. 5–6

This Service Specification document is divided into the following Chapters:

  • Chapter 1 - Introduction (current): Provides an overview of the document, including its purpose, scope, intended audience, and structure..
  • Section 2 - High-Level System Architecture: Describes the overall architecture of the CopernicusLAC platform, highlighting the key components and their roles within the system. This section serves as a foundation for understanding how the system components interact with external systems detailed in subsequent sections.
  • Section 3 - Data Ingestion Interfaces: Details the interfaces related to the ingestion of data into the system, focusing on the integration with the Copernicus Data Space Ecosystem (CDSE). It includes specifications on data formats, protocols, and security measures.
  • Section 4 - Data Discovery Interfaces: Focuses on the interfaces that enable data discovery within the system, specifically the STAC API. This section outlines the API endpoints, data structure, and security considerations.
  • Section 5 - Data Visualisation Interfaces: Describes the interfaces used for data visualisation, including those related to Titiler and the Web Map Tile Service (WMTS).

It covers the technical requirements, data rendering processes, and API specifications.

  • Section 6 - Data Access Interfaces: Addresses the interfaces involved in data access, particularly those using S3-compatible storage and Signed URLs. This section covers the data retrieval process, security measures, and performance considerations.
