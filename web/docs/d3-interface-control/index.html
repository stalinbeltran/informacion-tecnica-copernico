D3 — Interface Control Document

Documento de control de interfaces (ICD): cómo se integran sistemas externos con la plataforma CopernicusLAC, con endpoints reales, ejemplos de consulta STAC, teselas WMTS y descarga mediante URLs firmadas.

Documento de diseño de interfaces (D3) de Terradue para ESA. A diferencia de D2, que describe la arquitectura interna, este documento define el contrato hacia fuera: qué protocolos, formatos y esquemas de seguridad rigen las interacciones entre la plataforma del Centro CopernicusLAC y los sistemas externos —proveedores de datos, servicios de terceros y usuarios finales—. Cubre cuatro áreas funcionales: ingesta (integración con el Copernicus Data Space Ecosystem, formatos aceptados, validación y códigos de salida), descubrimiento (API STAC con colecciones, queryables y filtrado CQL2 en sus variantes JSON y texto), visualización (imágenes de vista previa y endpoints WMTS/XYZ con plantillas de teselas) y acceso a datos (esquema signed_url_auth para generar URLs pre-firmadas de descarga temporal desde el almacenamiento S3). Es el documento con más ejemplos concretos de petición y respuesta.
