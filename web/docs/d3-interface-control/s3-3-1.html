Accepted Data Format

Metadatos conformes a STAC para la recolección; GeoTIFF, COG u otros estándares acordados cuando hay copia o calibración.

pp. 15

The ingestion process supports multiple formats tailored to each ingestion level. For metadata harvesting, the system processes STAC-compliant metadata files. For dataset copying and calibration, the ingestion interface accepts data in formats such as GeoTIFF, Cloud-Optimized GeoTIFF (COG), or other user-defined standards, ensuring compatibility with downstream workflows.
