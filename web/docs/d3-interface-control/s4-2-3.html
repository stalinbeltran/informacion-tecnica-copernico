Obtain Filter Criteria

GET .../queryables devuelve los campos por los que se puede filtrar (datetime, geometry, eo:cloud_cover…), con ejemplo de respuesta.

EndpointJSON
pp. 19

The STAC API provides mechanisms to obtain and utilise filter criteria, known as "queryables." These criteria allow users to refine their searches based on specific metadata fields such as date/time, geographic coverage, and cloud cover percentage. The filter criteria can be retrieved using the following method:

  • GET /collections/<collection-id>/queryables: Returns a JSON document with information about applicable filter criteria.

Example of a filter criteria response: { ... "properties": { ... "datetime": { "type": "string", "title": "Acquired", "format": "date-time", "pattern": "(\\+00:00|Z)$", "description": "Datetime" }, "geometry": { "$ref": "https://geojson.org/schema/Feature.json", "title": "Item Geometry", "description": "Item Geometry" }, "eo:cloud_cover": { "$ref": "https://stac-extensions.github.io/eo/v1.0.0/schema.json#/definitions/fieldsproperties/eo:clou d_cover" } } }

This response provides the necessary information to construct search queries using the identified criteria.
