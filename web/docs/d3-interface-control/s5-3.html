Overview Images

Las vistas previas se publican como asset del STAC Item con role "overview"; ejemplo con los parámetros de color, remuestreo y reescalado.

JSON
pp. 28–29

Overview images are simplified visual representations of the EO products, designed to provide a quick preview of the data. These images are accessible via a specific STAC Item asset, which includes the following key attributes:

  • href: The URL that points to the location of the overview image.
  • role: Set to "overview", indicating that this asset is intended as a preview of the product.

Example of a STAC Item with an overview image:

-

{ ... features: [ { ... "assets": { ... "overview": { "href": "<view-url>/collections/sentinel-s2-l1c-cogs/items/S2A_MSIL1C_20231122T102331_N0509_R065_T32TM R_20231122T122209/preview.png?&assets=red&assets=green&assets=blue&color_formula=Gamma%20RGB%2 01.5%20Saturation%201%20Sigmoidal%20RGB%2010%200.3&max_size=1024&resampling=cubic&rescale=1,75 00&rescale=1,7500&rescale=1,7500", "type": "image/png",

"roles": [ "overview" ], "title": "Overview" }, ... } } ] }

This example shows how the href attribute links to an image, which is generated with specific parameters, such as resampling method and colour formula, to create a visually effective overview of the EO data.
