Visualisation Types

Dos tipos: imágenes de vista previa estáticas y endpoints WMTS con teselas para mapas navegables.

pp. 28

There are two primary types of visualisations supported by the CopernicusLAC system:

  1. Overview Images: These are static images providing a quick visual summary of a product.
  2. WMTS Endpoints: These provide tile-based visualisations that can be used in interactive maps, allowing users to explore data at different zoom levels and geographic extents.
