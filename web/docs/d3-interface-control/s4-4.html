Note the following information (highlighted in red above):

  • Links point to related resources, such as the collection or the catalogue.
  • Among the links, there are also visualisation links to a tile server (see Tiles).
  • Assets are downloadable resources containing the original data represented by the STAC item (image files, data files, other metadata files etc.).
  • An asset may have information about the authentication method to be used for the download (e.g. signed URLs). In that case, there is a reference to an authentication scheme defined at the item/properties level (see below)
  • Properties represent basic metadata fields (collection-specific) that can be used for filtering.
  • Among the properties there can be a series of authentication schemes, i.e. instructions to which assets can refer in their download authentication information (see above).
