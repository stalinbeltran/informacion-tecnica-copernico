Direct Metadata Access

GET .../items y GET .../items/<item-id> devuelven un FeatureCollection o un Feature GeoJSON, sin necesidad de filtrar.

Endpoint
pp. 18–19

Metadata about specific items within a collection can be accessed directly without filtering. The following methods are supported:

  • GET /collections/<collection-id>/items: Retrieves a GeoJSON FeatureCollection representing all items within the specified collection.
  • GET /collections/<collection-id>/items/<item-id>: Retrieves a single GeoJSON Feature representing the item identified by <item-id>.

For example, to access metadata for a specific Sentinel-2 item, the following request can be made: https://<discover-server>/collections/sentinel-s2-l1c-cogs/items/S2A _MSIL1C_20231122T102331_N0509_R065_T32TMR_20231122T122209

This request would return a GeoJSON Feature with detailed metadata about the specific Sentinel-2 product.
