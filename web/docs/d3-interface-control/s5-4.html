Web Map Tile Service (WMTS) Endpoints

Los endpoints WMTS renderizan los datos como teselas dinámicas integrables en mapas web.

2 apartadospp. 29–30

The CopernicusLAC system provides WMTS endpoints for visualising EO data in web applications. These endpoints allow for the dynamic rendering of data as tiles, which can be integrated into interactive maps, enabling users to zoom in and out and explore the data geographically.
