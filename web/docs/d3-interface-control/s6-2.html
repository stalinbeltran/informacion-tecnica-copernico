Downloading Data with Signed URLs

Para descargar un asset almacenado en objetos hay que generar una URL pre-firmada mediante el esquema signed_url_auth declarado en los metadatos del STAC Item.

4 apartadospp. 31–34

Accessing STAC item assets that are stored in object storage requires generating a pre-signed URL. This URL grants temporary access to the asset, allowing it to be downloaded via HTTP. The pre-signing process is handled through a specific authentication scheme, typically using the signed_url_auth method as defined in the STAC item metadata.
