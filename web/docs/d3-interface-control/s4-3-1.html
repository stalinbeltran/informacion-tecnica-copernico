Filtering using CQL2-JSON (POST)

Cuatro ejemplos completos de cuerpo CQL2-JSON: por fecha (T_INTERSECTS), por área (S_INTERSECTS), por cobertura de nubes y combinando criterios.

POSTEjemplos
pp. 20–22

Example of filtering by date/time: { "collections": [ "sentinel-s2-l1c-cogs" ], "filter-lang": "cql2-json", "filter": { "op": "T_INTERSECTS", "args": [ { "property": "datetime" }, { "interval": [ "2023-11-22T00:00:00Z", "2023-11-23T00:00:00Z" ] } ] } }

Example of filtering by geographic area: { "collections": [ "sentinel-s2-l1c-cogs" ], "filter-lang": "cql2-json", "filter": { "op": "S_INTERSECTS", "args": [ { "property": "geometry" }, { "type": "Polygon", "coordinates": [ [ [7.8, 45.2], [9.0, 45.2], [9.0, 45.8], [7.8, 45.8], [7.8, 45.2] ] ]

} ] } }

Example of filtering by cloud cover percentage: { "collections": [ "sentinel-s2-l1c-cogs" ], "filter-lang": "cql2-json", "filter": { "op": "<", "args": [ { "property": "eo:cloud_cover" }, 10 ] } }

Example of filtering by a combination of criteria (date/time and cloud cover percentage):

{ "collections": [ "sentinel-s2-l1c-cogs" ], "filter-lang": "cql2-json", "filter": { "op": "and", "args": [ { "op": "T_INTERSECTS", "args": [ { "property": "datetime" }, { "interval": [ "2023-11-22T00:00:00Z", "2023-11-23T00:00:00Z" ] } ] }, { "op": "<", "args": [ {

"property": "eo:cloud_cover" }, 0 ] } ] } }
