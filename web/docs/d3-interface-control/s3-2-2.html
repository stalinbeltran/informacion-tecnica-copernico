Initial Data Validation

El Event Bus dispara la ingesta; el workflow lee la plantilla desde el Registry y obtiene las imágenes de ingesta necesarias.

pp. 14

Upon receiving the data, the system triggers the ingestion process via the Event Bus, which handles the topic related to new data acquisition. The ingestion workflow then reads the application workflow template from the Registry and obtains the necessary ingestion images.
