Data Transfer Protocols

Protocolo aún no cerrado; se prevé HTTPS, el que ya emplea el almacenamiento S3. La decisión final depende de los servicios del CDSE.

Abierto
pp. 15

The data transfer protocol is not fully defined yet but is expected to involve secure methods such as HTTPS that is the data transfer protocol employed for the S3-based storage system. The final choice will be determined based on the capabilities of the services provided by the Copernicus Data Space Ecosystem.
