Tile Request Format

Cómo sustituir los marcadores {z}, {x} e {y} por nivel de zoom, columna y fila para pedir una tesela concreta, con ejemplo de URL resuelta.

Ejemplo
pp. 30

To request a specific tile, the placeholders{z}, {x}, and {y}, in the tile link template must be replaced with actual values corresponding to the desired zoom level and geographic location on the tile grid. For example: <view-url>/collections/sentinel-s2-l1c-cogs/items/S2A_MSIL1C_2023112 2T102331_N0509_R065_T32TMR_20231122T122209/tiles/WebMercatorQuad/10/ 525/391@1x?&assets=red&assets=green&assets=blue&color_formula=Gamma% 20RGB%201.5%20Saturation%201%20Sigmoidal%20RGB%2010%200.3&rescale=1, 6000&rescale=1,6000&rescale=1,6000

In this request:

  • The {z} placeholder is replaced with 10, indicating the zoom level.
  • The {x} and {y} placeholders are replaced with 525 and 391, representing the tile’s column and row in the grid, respectively.

This URL will return a tile image showing the true colour composite of the EO product at the specified zoom level and location.
