Generating a Signed URL

Petición POST al endpoint de autorización con la URL S3 codificada y un token Bearer; ejemplo con cURL.

cURL
pp. 33–34

To generate a signed URL, a POST request must be made to an authorization endpoint. This request includes the S3 URL of the asset as well as authentication credentials.

Example request using cURL:

curl -X 'POST' \ 'https://<sign-url>?url=s3%3A%2F%2Fsentinel-2%2Fred.tif' \ -H 'Authorization: Bearer eyJ...cmQ' \

-d ''

In this request:

  • The url parameter contains the encoded S3 URL of the asset.
  • The Authorization header includes a Bearer token, which is used to authenticate the request.
