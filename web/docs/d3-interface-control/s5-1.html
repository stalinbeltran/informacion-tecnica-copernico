Overview

La visualización permite explorar los datos EO mediante representaciones visuales: imágenes de resumen y teselas para mapas interactivos.

pp. 28

The Data Visualization component of the CopernicusLAC system provides users with the capability to visually explore EO data through various forms of visual representations. This section describes the methods and formats used to visualise data, including overview images and Web Map Tile Service (WMTS) endpoints, which are integral for creating interactive maps in web applications.
