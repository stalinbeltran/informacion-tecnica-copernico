Key Components

Los ocho componentes centrales —ingesta, procesamiento, descubrimiento y acceso, front-end, espacio de trabajo, seguridad, empaquetado y despliegue, gestión de recursos— con su función e integración.

pp. 9–10

The platform comprises several core components, each of which plays a role in the system's overall functionality:

  • Data Ingestion
    • Functionality: The Data Ingestion component is responsible for acquiring EO data from various sources, including satellites, ground stations, and external data providers. This component supports multiple data formats and ingestion protocols to accommodate a diverse range of data sources.
    • Integration: Data Ingestion interfaces with the Data Processing component to pass on validated and pre-processed data. It also interacts with the storage systems for cataloguing and long-term storage.
  • Data Processing
    • Functionality: The Data Processing component is central to the platform’s capability to transform raw EO data into actionable insights. It manages the execution of complex workflows, orchestrating tasks across a distributed computing environment.
    • Integration: This component interacts closely with Data Ingestion for processing incoming data and with Data Discovery and Access for storing and retrieving processed outputs. It also interfaces with the Application Execution Engine for deploying and running EO algorithms.
  • Data Discovery and Access
    • Functionality: The Data Discovery and Access component allows users to search, retrieve, and visualise EO data. It provides tools for filtering datasets based on spatial, temporal, and thematic criteria, leveraging metadata cataloguing systems.
    • Integration: This component interfaces with the storage systems to access metadata and data files, and with Front-End Services to provide users with search and visualisation capabilities.
  • Front-End Services
    • Functionality: Front-End Services provide the user interface for interacting with the CopernicusLAC platform. This includes the web portal, interactive development environments, and web applications that allow users to access data, run analyses, and visualise results.
    • Integration: These services interface with the Data Processing and Data Discovery components to deliver processed data and analysis tools to the end-users. They also interact with the User Workspace to provide a smooth user experience.
  • User Workspace
    • Functionality: The User Workspace is a personalised environment where users can manage, process, and analyse EO data. It provides access to the necessary tools and resources in a private, user-specific setting.
    • Integration: The User Workspace integrates with Front-End Services for data access and interaction, and with Data Processing for executing customised workflows.
  • Security and Access Control
    • Functionality: This component ensures the platform’s security by managing authentication, authorization, and access control. It safeguards data and services against unauthorised access and potential threats.
    • Integration: Security and Access Control interfaces with all other components to enforce security policies, manage user roles, and ensure compliance with regulatory standards. Keycloak is the central tool used for identity and access management across the platform.
  • Application Packaging and Deployment
    • Functionality: The Application Packaging and Deployment component manages the lifecycle of EO applications, from packaging as Docker containers to deployment across the platform. It ensures that applications are consistent, scalable, and easily deployable.
    • Integration: This component interacts with the Data Processing and Resource Management components to deploy applications within the platform’s infrastructure. It also interfaces with the Harbor container registry and Kubernetes for container management and orchestration.
  • Resource Management
    • Functionality: Resource Management is responsible for provisioning, managing, and optimising the platform’s computational and storage resources. This component ensures that the platform can scale to meet user demands.
    • Integration: Resource Management interfaces with Crossplane for dynamic resource provisioning and with monitoring tools to optimise resource usage across the platform. It plays a crucial role in maintaining the platform’s performance and cost-effectiveness.
