Practical Example

Caso completo de descarga de una banda NIR de Sentinel-2: identificar el asset, generar la URL firmada y descargar.

Ejemplo
pp. 34–35

Consider a scenario where a user wants to download a specific asset from the CopernicusLAC system, such as a NIR band image from Sentinel-2 data. The process would be as follows:

  1. Identify the Asset

The user identifies the desired asset from the STAC item metadata, noting the S3 URL and the required authentication scheme (signed_url_auth).

  1. Generate Signed URL:

The user sends a POST request to the authorization endpoint with the asset’s S3 URL. Example cURL request: curl -X 'POST' \ 'https://<sign-url>?url=s3%3A%2F%2Fsentinel-2%2Fred.tif' \ -H 'Authorization: Bearer eyJ...cmQ' \ -d ''

  1. Download the Asset:

Upon receiving the signed URL in the response, the user can either manually download the asset using the provided URL or rely on the automatic redirection (if enabled) to initiate the download immediately.

This method ensures that data access within the CopernicusLAC system is both secure and efficient, protecting sensitive EO data while providing users with the flexibility to download assets as needed.
