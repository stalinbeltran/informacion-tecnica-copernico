Filtering using CQL2-TEXT (GET)

Los mismos cuatro casos expresados como query string CQL2-TEXT para peticiones GET.

GETEjemplos
pp. 22

This method provides a serialised form of querying similar to CQL2-JSON. The following are equivalent query strings for the examples above:

  • Filter by date/time:
    • filter-lang=cql2-text&collections=sentinel-s2-l1c-cogs&fi lter=datetime%3E=%272023-11-22T00:00:00Z%27%20and%20datet ime%3C%272023-11-23T00:00:00Z%27
  • Filter by geographic area:
    • filter-lang=cql2-text&collections=sentinel-s2-l1c-cogs&fi lter=S_INTERSECTS(geometry,%20POLYGON((7.8%2045.2,9.0%204 5.2,9.0%2045.8,7.8%2045.8,7.8%2045.2)))
  • Filter by cloud cover percentage:
    • filter-lang=cql2-text&collections=sentinel-s2-l1c-cogs&fi lter=eo:cloud_cover%3C10
  • Filter by a combination of criteria (date/time and cloud cover percentage):
    • filter-lang=cql2-text&collections=sentinel-s2-l1c-cogs&fi lter=datetime%3E=%272023-11-22T00:00:00Z%27%20and%20datet ime%3C%272023-11-23T00:00:00Z%27%20and%20eo:cloud_cover%3 C10
