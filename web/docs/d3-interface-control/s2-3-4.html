Security and Access Control

Keycloak centraliza identidad y control de acceso; MFA y RBAC limitan cada usuario a lo necesario, con registros de auditoría.

pp. 12

The platform's security framework is centralised through the Authentication and Authorization component, which uses Keycloak for identity management. All access to data, applications, and services is controlled by Keycloak, which enforces policies based on user roles and permissions.

Multi-Factor Authentication (MFA) and Role-Based Access Control (RBAC) ensure that users only have access to the resources necessary for their roles, reducing the risk of unauthorised access. Security logs are maintained to track user activity, providing an audit trail for compliance and security analysis.
