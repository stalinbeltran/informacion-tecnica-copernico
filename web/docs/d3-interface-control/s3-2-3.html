Ingestion Process Execution

El Workflow Engine instancia y ejecuta la ingesta; las acciones concretas (indexar, descargar y validar, o calibrar) dependen del nivel elegido.

pp. 14

The ingestion instance is instantiated and executed by the Workflow Engine, which handles the data acquisition and processing. At its full scope the system computes the data, enriches and posts the STAC item to the STAC FastAPI, and stores the processed product in the S3 Data Bucket, however depending on the ingestion level the actions are:

  • For metadata harvesting, the ingestion instance processes and indexes only the metadata, ensuring its alignment with the SpatioTemporal Asset Catalog (STAC) specification.
  • For metadata harvesting and dataset copying, the ingestion workflow downloads the dataset, validates its integrity, and stores it in the platform’s S3-compatible object storage.
  • For metadata harvesting with calibration, the workflow applies predefined calibration routines, such as georeferencing or format conversion, before registering the dataset and its metadata for discovery and access.
