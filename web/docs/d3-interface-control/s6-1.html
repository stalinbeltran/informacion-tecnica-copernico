Overview

URLs pre-firmadas con acceso temporal, pensadas para máquina a máquina; el geobrowser las usa de forma transparente y los workflows CWL las evitan gracias al mecanismo de stage-in.

pp. 31

The Data Access interfaces in the CopernicusLAC system are designed to facilitate secure and efficient access to EO data stored in object storage. These interfaces allow users to download specific assets from the system, with access control enforced via pre-signed URLs. This section provides an overview of the mechanisms used to generate and use these signed URLs, ensuring that only authorised users can retrieve the data.

The signed URLs interface is designed primarily for machine-to-machine (M2M) access to S3-compatible object storage resources. Upon authentication and authorization, a client may request a pre-signed HTTPS URL that grants time-limited access to a specific object, without requiring the client to handle or store long-term credentials. This mechanism ensures secure, auditable, and scalable access to EO datasets and platform-generated products.

This interface is also used internally by the platform components and externally by authenticated clients. More specifically:

  • Web UI Integration (Human-to-Machine access): The CopernicusLAC geobrowser interface will use this API transparently to allow users to download data via a one-click interaction. The front-end will handle the retrieval of a signed URL and trigger the download automatically, ensuring ease of use without exposing access tokens or object paths directly.
  • Workflow Integration (Machine-to-Machine access): For data processing services integrated via the CWL, there is no need for services to generate or manage signed URLs themselves. Instead, the platform handles data staging through a stage-in mechanism. This process ensures that input datasets are made available as local file paths inside the containerized service execution environment, avoiding the need for remote access logic within the service components.

This approach ensures consistency with best practices for data access security, scalability for high-throughput processing, and usability for human-facing interfaces.
