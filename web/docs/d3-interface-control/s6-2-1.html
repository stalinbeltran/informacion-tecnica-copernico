Authentication Scheme

Definición completa del esquema signed_url_auth en las properties del item: método, parámetros de cuerpo y cabecera, responseField y authorizationApi; y cómo el asset lo referencia con auth:refs.

JSON
pp. 32–33

The signed_url_auth scheme is a standard approach for securing access to assets in object storage. The scheme is defined within the STAC item's properties and specifies how a pre-signed URL can be obtained.

Example of a STAC item asset with the signed_url_auth scheme:

{ ... features: [ { ... "properties": { ... "auth:schemes": { "signed_url_auth": { "type": "signedUrl", "flows": { "authorizationCode": { "method": "POST", "parameters": { "url": { "in": "body", "schema": { "type": "string", "examples": "s3://<storage-base>/optical-calibration-sj889/S2B_MSIL2A_20230922T095649_N0509_R122_T33TUG_20 230922T125953-calibrated/red.tif" }, "required": "true", "description": "asset URL" }, "redirect": { "in": "body", "schema": { "type": "boolean", "examples": "true" }, "required": "true", "description": "indicate if the response include a 302 for an automatic redirect with 'Location' header" }, "Authorization": { "in": "header", "schema": { "type": "string", "examples": "Bearer secretKey1234567890" }, "required": "true", "description": "Authentication credentials"

} }, "responseField": "signed_url", "authorizationApi": "https://example.com/signed_url/authorize" } }, "description": "Provides an authenticated download link for an asset URL" } }, ... } } ] }

In this example, the asset located at the specified S3 URL is protected by the signed_url_auth scheme, meaning that a signed URL must be generated to access it.

The authentication scheme to be used is specified in the asset information of the STAC item, e.g.: { ... "assets": { "nir": { "href": "s3://<storage-base>/sentinel-2-l1c-ingestion-xvv8c/S2A_MSIL1C_20231122T102331_N0509_R065_T32T MR_20231122T122209/r-nir.tif", ... "auth:refs": [ "signed_url_auth" ], ... }, ... }, ... }
