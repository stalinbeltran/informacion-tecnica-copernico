Interaction between Data Processing and User Interfaces

Los resultados del procesamiento se devuelven al almacenamiento con metadatos actualizados; los usuarios los descubren y consumen desde los servicios de front-end.

pp. 11–12

As the Data Processing component completes the execution of workflows, the results are stored back into the storage system, with updated metadata added to the catalog. Users can then discover these processed datasets through the Data Discovery and Access interfaces.

Users interact with the platform via Front-end Services, which provide a unified interface to access data, run processing tasks, and visualise results. These services, including web applications, notebooks, and integrated development environments (IDEs), are tightly integrated with the User Workspace component, allowing users to manage their data and processing tasks.
