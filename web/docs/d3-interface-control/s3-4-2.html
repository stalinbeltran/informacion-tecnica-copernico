Access Control

Acceso restringido a entidades autorizadas, con autenticación segura previsiblemente basada en OAuth2.

pp. 15

Access to the ingestion interface is restricted to authorised entities. The system uses secure authentication methods, potentially including OAuth2, to manage access control.
