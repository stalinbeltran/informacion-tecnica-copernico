Filtering

Dos vías de filtrado en /search: GET con CQL2-TEXT en la query string y POST con CQL2-JSON en el cuerpo, que admite consultas más complejas.

2 apartadospp. 19–22

The STAC search endpoint supports two methods of filtering, allowing users to search for items that match specific criteria:

  • GET /search: Uses URL query strings with filtering parameters (CQL2-TEXT).
  • POST /search: Uses a request body containing filtering criteria formatted as a CQL2-JSON object.

Both methods achieve similar results, though HTTP POST allows for more complex queries. Below are examples of filtering using these methods.
