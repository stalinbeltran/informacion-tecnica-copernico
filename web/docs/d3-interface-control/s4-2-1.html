Obtain Collection Information

GET /collections y GET /collections/<id>, con la respuesta JSON completa de la colección sentinel-s2-l1c-cogs como ejemplo.

EndpointJSON
pp. 17–18

The STAC API allows users to obtain information about the available collections within the catalog. Two primary methods are available:

  • GET /collections: Retrieves a JSON document containing all available collections.
  • GET /collections/<collection-id>: Retrieves detailed information about a specific collection identified by <collection-id>.

Each collection is described by metadata, including spatial and temporal extents, links to further information, and other relevant details.
