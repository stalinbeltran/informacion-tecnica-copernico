Error Detection

Comprobaciones distintas por nivel; los datos problemáticos se mueven a almacenamiento temporal y se notifica al sistema de monitorización.

pp. 16

The system continuously monitors the ingestion process for errors, considering the different levels:

  • For metadata harvesting, it verifies metadata integrity and completeness.
  • For dataset copying, it validates file integrity using checksum verification.
  • For calibration workflows, it ensures that all transformation routines are executed correctly and flags any discrepancies for operator review.

If any issues arise, such as incorrect file formats or invalid STAC Items, the system will move the problematic data to temporary storage and notify the monitoring system.
