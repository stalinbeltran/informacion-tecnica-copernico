High-Level System Architecture

Arquitectura de alto nivel como base para entender las interfaces: visión general, los ocho componentes clave y cinco escenarios de interacción entre ellos. Remite a D2 para el detalle.

The CopernicusLAC platform is designed as a modular, cloud-native system that supports the entire lifecycle of Earth Observation (EO) data, from acquisition and processing to discovery, access, and analysis. This section provides an overview of the platform's architecture, highlighting the key components and their roles within the system. Understanding this architecture is crucial for comprehending the interfaces detailed in subsequent sections.

This high-level system architecture aligns with the detailed descriptions provided in the D2 System Architecture Description document. The D2 document elaborates on the specific technologies, workflows, and interactions within each component, providing a deeper understanding of the platform’s operation. For detailed diagrams, technical specifications, and component interactions, refer to the D2 System Architecture Description.
