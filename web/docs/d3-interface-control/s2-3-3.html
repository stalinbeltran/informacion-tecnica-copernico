Application Deployment and Execution

Las aplicaciones EO se empaquetan como contenedores Docker con manifiesto CWL, se despliegan con Kubernetes y Helm, y se ejecutan por lotes o en tiempo real.

pp. 12

EO applications are packaged and stored in the Application Repository as Docker containers and associated Application Package manifest encoded using the Common Workflow Language (CWL). The containers include all necessary dependencies, ensuring that applications can be deployed consistently across different environments within the platform.

The deployment of these applications is managed by Kubernetes, which is responsible for orchestrating the containers across the platform's infrastructure. Helm charts are used to define deployment configurations, enabling repeatable and scalable deployment processes.

Once deployed, these applications can be executed by the Data Processing component or directly by users through the Front-end Services. The platform supports both batch processing and real-time processing, catering to a wide range of use cases.
