Example Workflow

El flujo resumido en tres pasos: pedir la URL firmada, recibirla y descargar el asset.

pp. 34
  1. Request Signed URL: The user or application requests a signed URL by sending a POST request to the authorization endpoint with the asset's S3 URL and authentication credentials.
  2. Receive Signed URL: The server responds with a signed URL that provides temporary access to the asset.
  3. Download Asset: The user or application can then use the signed URL to download the asset directly from the object storage.
