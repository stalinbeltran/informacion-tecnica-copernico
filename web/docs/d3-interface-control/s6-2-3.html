Response and Redirection

La respuesta JSON contiene el campo signed_url con la firma AWS4-HMAC-SHA256 y su caducidad; con redirect activado se devuelve además una cabecera Location.

JSON
pp. 34

The response to the POST request is a JSON object that contains the signed URL, which can be used to download the asset. If the redirect parameter is set to true, the response will also include a Location header that automatically redirects the user to the signed URL.

Example response: { "signed_url": "<storage-url>/sentinel-2/red.tif?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=36TH83i1lW kOseYhN96Z%2F20240122%2Fit-rom%2Fs3%2Faws4_request&X-Amz-Date=20240122T134237Z&X-Amz-Expires=1 20&X-Amz-SignedHeaders=host&X-Amz-Signature=2fc41c51180a954d93f38b2b868ad9026328fa384a975305d9 052715fdbef80b" }

If redirection is enabled, the resource will be automatically downloaded from the signed URL provided in the response.
